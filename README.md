# Vanishing Days · 배니싱 데이즈

Unity 6000.3.8f1 기반 한국어 텍스트 생존 게임. v0.5는 생존 루프, 라디오~최동림 첫 만남과 후속 재회, 단계별 탐색과 문 보강을 구현합니다. 화면은 **9:16**, UI 기준 900×1600, 기본 실행 창 540×960입니다.

## 실행

1. `Assets/Scenes/Prototype.unity`를 열고 **Play**.
2. 시작 화면에서 쉬움 / 보통 / 어려움을 선택하고 **게임 시작**.
3. 기존 오프닝과 닉네임 입력을 마친 뒤, 기록지 #001의 마지막 **다음**을 누르면 **송파구 자취방**에서 시작합니다.
4. 저장이 있으면 시작 시 **기록 이어 읽기**로 복원할 수 있습니다.

Windows 실행 파일: `Builds/Windows/VanishingDays.exe` (로컬 빌드 결과이며 Git에는 포함하지 않음).

Unity 메뉴 `Vanishing Days/Build Windows prototype`으로 다시 빌드합니다. 에디터에서 본편만 테스트할 때는 Prototype 오브젝트의 **Skip Opening In Editor**를 켭니다. 일반 빌드는 이 옵션을 무시합니다.

한글 UI는 `Assets/Resources/Fonts/NanumGothic-Regular.ttf`를 빌드에 포함해 사용합니다. 실행 PC의 시스템 폰트 설치 여부와 관계없이 오프닝·닉네임·본편에 같은 폰트를 적용합니다. 나눔고딕의 출처는 [Google Fonts](https://github.com/google/fonts/tree/main/ofl/nanumgothic)이며 배포 라이선스는 같은 폴더의 `OFL.txt`에 포함합니다. 빌드 전 폰트 데이터 포함 설정과 한글 글리프를 검사합니다.

모바일 웹은 `Vanishing Days/Build Web prototype`으로 `Builds/WebGL`에 빌드합니다. 서버의 압축 헤더 없이 실행할 수 있도록 Gzip과 Unity Decompression Fallback을 사용합니다. 이름 입력용 HTML 입력칸에는 키보드 포커스 전부터 16px 글자를 적용해 브라우저 자동 확대를 방지합니다. 입력을 마치면 키보드 포커스를 해제하고 화면 위치·크기 갱신을 재시도하며, 기본 Unity 템플릿의 확대·축소 제한도 해제합니다. 관련 브라우저 이벤트 검사는 `node Tests/MobileInputViewport.test.cjs`로 실행합니다. 실제 iOS·Android 키보드 동작은 기기에서 별도로 확인해야 합니다.

## 생존 플레이

- **생활**: 집에서 요리·식사·수면. 가스는 충분하며, 쉬움에서만 물이 무제한입니다. 보통·어려움은 시간 경과와 요리로 물을 소비합니다.
- **외출**: 처음에는 집·편의점만 표시됩니다. 편의점 1회 수색 → 빈집, 빈집 1회 수색 → 고등학교, 고등학교 2회 수색 → 약국 순으로 길을 발견합니다. 넓어진 지도를 드래그하거나 상하좌우 화살표로 살피고 현재 위치 버튼으로 돌아올 수 있습니다. 수색률·잔량 비율과 소진 여부만 표시하며 남은 품목·수량은 공개하지 않습니다. 미방문 장소는 잔량 미확인으로 표시합니다. **이동하기**를 눌러야 출발하며 지도 확인에는 시간이 흐르지 않습니다.
- **물품**: 몸에 지닌 물건과 집에 둔 물건을 구분합니다. 맨 위의 붕대·알약·소독약에서 **치료**를 누르면 약품 1개로 부상 1곳을 치료합니다. 음식은 먹고 옷·무기는 착용/해제할 수 있습니다.
- **기록**: 작성자 닉네임과 생존 행동·획득·손실을 확인합니다.
- **메뉴**: 저장/로드, 보안·정비, 새 기록. 설치 시 침입 저항과 외부 주목도가 함께 변합니다.
- **라디오**: 고등학교에서 확보한 뒤 집에서 켜면 SP 첫 방송을 읽고 지도에 제보 장소를 해금합니다. 직접 낮에 방문해 배분 구역에 접근하면 군중 사고와 최동림의 구조로 이어집니다. 방송을 듣거나 장소에 도착하는 것만으로 사건이 시작되지는 않습니다. 밤에는 현장 흔적만 확인하며 다시 방문할 수 있습니다. 첫 만남 후에는 자유 생존으로 복귀합니다.
- **동림과의 재회**: 첫 만남 다음 날부터 낮에 빈집에 방문하면 두 번째 만남과 철물점 뒷창고가 열립니다. 그 다음 날부터 낮에 고등학교에서 세 번째 만남을 마치면 주민회관 지하를 발견합니다. 이후 이틀 간격으로 빈집·학교를 번갈아 순찰하는 동림과 소식을 나누거나 소지 식량 1개를 붕대 1개로 교환합니다. 다음 날짜·장소는 지도에 표시하며 물자를 다 턴 장소에서도 만날 수 있습니다.
- **문·정비**: 집에서는 라디오 보유 여부와 관계없이 하단 **문·정비** 버튼으로 접근합니다. 빗장 → 문틀 → 이중 잠금 3단계를 순서대로 보강하며 집에 보관한 목재·생활도구와 작업 시간을 사용합니다. 보안 화면은 스크롤하며 기존 아날로그·디지털 설비와 함께 관리합니다.
- **전국 소멸 속보**: 라디오를 얻고 가락시장 군중 사건을 마치면, 다음 날짜 전환부터 하루 한 곳의 소멸 제보를 받습니다. 서울의 밀집 대피소·빈 건물 20곳과 지방 읍 30곳을 중복 없이 무작위로 선택합니다. 속보 확인 후 전국 개략도에서 날짜별 기록을 다시 볼 수 있으며, 라디오 화면과 생존 기록에서도 접근합니다. 탐색 장소의 물자·해금과 별개의 전국 소식입니다.

낮에는 굶주린 사람에게 물자를 내어주거나 저항할 수 있습니다. 밤에는 조우가 드물지만 발견되면 부상과 소지품 손실이 발생합니다. 집을 비우면 집 보관 물품도 별도로 약탈될 수 있습니다.

시작 HP는 **500/500**, 게임오버는 현재 HP **0**. 부상·허기로 회복 상한이 내려가면 현재 체력도 즉시 그 이하로 제한합니다. 예를 들어 현재 410에서 상한이 350이 되면 현재 체력은 350이 됩니다. 이미 상한보다 낮은 체력은 추가로 깎지 않습니다. 상한이 회복돼도 잃은 체력이 자동 복구되지는 않습니다. 막힌 영역은 체력바에 표시합니다.

집에서 **연속 6시간 휴식마다 부상 1곳**이 회복됩니다. 2시간씩 이어 쉬거나 아침/밤까지 머무를 수 있습니다. 이동·수색·조리·식사·치료 등 시간이 드는 다른 행동을 하면 연속 휴식 진행이 초기화됩니다. 음식과 짧은 휴식의 HP 회복은 부상 자체를 제거하지 않습니다. 붕대·알약·소독약 치료는 **부상 1곳 회복 + 체력 20 회복**을 함께 적용하며, 회복된 상한을 넘지 않습니다. 허기는 따로 해결해야 합니다. 약품 소모량·회복량·치료 1시간·휴식 6시간은 조정 가능한 임시 밸런스입니다.

**정신력은 100/100으로 시작**하며 현재 수치·회복 가능한 상한·영구 손실을 상단 바에 표시합니다. 매일 오전 8시에 지난 24시간의 수면을 평가해, 6시간에서 부족한 시간당 정신력 3을 잃습니다. 6시간 초과 수면은 시간당 정신력 2를 회복합니다. 졸림은 깨어 있는 시간당 +4, 수면 시간당 -12로 0~100 사이에서 변합니다. 집의 수면 화면에서 2·6·8시간을 선택할 수 있습니다. 굶주린 상대의 식량을 강탈하면 정신력 상한 -10, 무기 저항으로 상대가 사망하면 -25가 적용되며 수면으로 이 상한을 복구할 수 없습니다. 무기 저항 성공 시 사망 확률은 임시 밸런스 15%입니다.

낮의 길거리 조우 중 15%(현재 이동당 약 4.5%)는 행상인입니다. 소지품으로 참치 2개→붕대 1개, 목재 3개→라면 2개, 스팸 2개→생활도구 1개 중 한 번 교환하거나 지나칠 수 있습니다. 건물 내부와 밤에는 행상인이 등장하지 않습니다. 저장 스키마 10은 졸림·수면·정신력 상한·미해결 거래를 보존하며 이전 저장은 현재 수면 평가까지 부족분을 유예합니다.

## 초기 물자

물품 화면에서 수량을 입력하거나 ± 버튼으로 조정한 뒤 **챙기기 / 보관**을 누릅니다. 쌀은 g 단위로 입력합니다. 집에서 **전체 보관**을 누르면 착용 장비를 제외한 소지품을 한 번에 집에 옮깁니다. 물품을 옮겨도 목록의 스크롤 위치는 유지되며 자동 저장됩니다.

| 난이도 | 스팸 | 참치캔 | 쌀 | 붕대 | 생수 |
|---|---:|---:|---:|---:|---:|
| 쉬움 | 10 | 10 | 10kg | 5 | 무제한 |
| 보통 | 5 | 5 | 3kg | 3 | 8병 |
| 어려움 | 3 | 1 | 1kg | 1 | 4병 |

생수 1병은 500ml입니다. 보통·어려움에서는 6시간마다 1병을 자동 소비하고, 없으면 체력 10을 잃습니다. 집에서는 집의 물을 먼저 마시며 없으면 소지품을 사용합니다. 외출 중에는 소지한 물만 사용하므로 미리 챙겨야 합니다. 밥·라면 요리는 집의 물 1병을 추가로 쓰고, 쉬움은 식수와 조리용 물 모두 무제한입니다. 편의점 4병·빈집 4병·고등학교 6병·약국 3병·철물점 2병·주민회관 8병의 유한 수색 풀에서 회당 최대 1병을 찾습니다. 지도에는 남은 품목·수량을 노출하지 않습니다. 관련 주기·피해는 임시 밸런스입니다.

물을 쓰지 않던 기존 기록에는 처음 한 번 보통은 집 6병·소지 2병, 어려움은 집 3병·소지 1병을 지급하고 기존 탐색 풀에 생수만 추가합니다. 음식·도구의 소진 상태는 유지하며, 새 버전에서 소모한 물을 다시 지급하지 않습니다.

상단의 **목마름 0~100**은 보통·어려움에서 시간당 10씩 오르며 식수를 마시면 0으로 돌아갑니다. 물이 없으면 다음 식수 주기에도 수치가 유지·증가하고 100에서 멈춥니다. 60 이상은 강조색으로 표시하며 기존 6시간당 식수 부족 피해를 그대로 적용합니다. 쉬움은 항상 0입니다. 버전 9 기록은 식수 경과 시간으로 목마름을 초기화하고 물·체력·정신력·소진 상태를 유지합니다.

모두 부르스타 1개, 라디오 0개, HP 500으로 시작합니다. 기록지 작성자와 최동림 장면 등 대본 속 주인공 이름은 입력한 닉네임을 사용합니다. 대본에는 `{PlayerNickname}` 자리표시자를 쓰고, `{PlayerNickname}(이)라고`처럼 받침에 따라 조사를 고릅니다. 닉네임이 없는 경우(에디터 테스트 등)에만 `ProtagonistScriptName`(안재현)을 대신 씁니다.

붕대는 집에 보관된 상태로 지급되며 외출 전 챙길 수 있습니다. 편의점에서 붕대·알약, 빈집에서 붕대·소독약, 고등학교에서 세 약품 모두를 찾을 수 있습니다. 기존 v0.3 저장에도 약품 파밍 풀을 한 번 추가하며, 초기 붕대를 다시 지급하거나 소진한 물품을 재생하지 않습니다.

## 저장

기존 JSON 저장 방식을 확장해 `Application.persistentDataPath/vanishing-days-v03.json`에 행동마다 자동 저장합니다. 메뉴에서 수동 저장/로드도 가능합니다. 난이도·날짜·시각·현재 위치·허기·부상·양쪽 인벤토리·수색 진행·장비·보안·진행 플래그·미해결 조우·난수 상태를 보관합니다. 이전 기록은 `.bak`으로 보관하며 정상 파일이 손상되면 백업을 읽습니다.

기존 `vanishing-days-v1.json`은 그대로 남겨 두고 자동 변환하거나 덮어쓰지 않습니다. 이전의 여덟 장소·HP 85 저장을 새 초기 물자로 잘못 해석하지 않기 위한 구분입니다.

내부 저장 버전은 10입니다. 버전 3·4·5·6·7·8·9 기록을 읽으면 기존 진행과 물자를 보존합니다. 정신력이 없던 기록에는 100/100을 추가하고, 현재 체력이 회복 상한을 넘었다면 상한으로 맞춥니다. 버전 3·4 기록에는 새 장소도 추가합니다. 소멸 속보가 없던 기록은 업데이트 후 다음 날짜 전환부터 시작하며 이미 지나간 날짜의 제보를 소급 생성하지 않습니다. 기존 정신력 수치·수신 내역·만남·장소 해금은 유지합니다. 수면 기능이 없던 기록은 다음 오전 8시 평가까지 수면 부족분을 유예합니다.

## 데이터와 검증

- 원고: `Assets/Resources/Opening/OpeningScriptData.json`. 앞서 다듬은 이석현의 기록을 유지합니다.
- 본편 정의: `Assets/Resources/Survival/SurvivalDefinitions.json`.
- 상태/행동: `Assets/Scripts/SurvivalState.cs`.
- 저장/검증: `Assets/Scripts/Survival/SessionSaveStore.cs`.
- UI/진입 연결: `Assets/Scripts/VanishingDaysGame.cs`.
- 오프닝 검증: `Vanishing Days/Validate opening flow`.
- 생존 검증: `Vanishing Days/Validate survival v0.3` 또는 `Validate game rules`.
- 확장 진행 검증: `Vanishing Days/Validate world progression v0.5` (장소 해금, 수색 잔량, 재회·교환·순찰 주기, 문 보강, 저장 변환).
- 전국 소멸 소식 검증: `Vanishing Days/Validate daily erasure news` (시작 조건, 날짜 전환, 독립 난수, 50곳 중복 방지, 수신 기록·확인 상태·저장 변환).
- 수면·정신력·행상인 검증: `Vanishing Days/Validate sleep morality and street trade` (57개 검증, 수면 합산·평가·회복, 영구 상한, 희귀 조우·교환 수량, 정보 비공개, 이전 저장 변환). `-vdSleepTrade` 검증 플레이어는 실제 지도 이동·수면·교환·강탈 버튼과 HUD·저장을 확인합니다.

**시간, 획득량, 수색 횟수, 요리 효과·양, 부상·허기, 조우 확률·피해, 장비 보정, 보안 비용·산식은 TEMP_BALANCE 프로토타입 값**입니다. 새 제보 장소명·이동 시간·군중 선택 효과도 조정 가능한 제안값입니다. v0.4 방송과 사건은 텍스트로 구현하며 조직 가입과 한지우는 다음 단계입니다.
