# v0.4 — 라디오부터 최동림 첫 만남

2026-10-23. 사용자가 전달한 `Vanishing_Days_P1_Radio_To_Dongrim_Design_v0.4.md`의 구현 요청에 따라 연결했습니다. 기존 오프닝, 의약품, 부상 회복, 네 초기 장소와 지도 렌더링 수정을 유지합니다.

## 플레이 흐름

1. 고등학교 수색으로 기존 방식대로 라디오를 확보합니다. 획득만으로 방송·사건·NPC가 자동 등장하지 않습니다.
2. 집의 **라디오를 켠다** 또는 메뉴의 **라디오 켜기**를 선택합니다. 첫 방송을 별도 스크롤 화면에서 읽고, 정보 카드가 기록에 남습니다. 날짜·시각·난수는 바뀌지 않습니다. 실제 음성은 이번 범위에서 제외하며 텍스트로 표시합니다.
3. 첫 방송 후 지도에 **제보 장소**가 나타납니다. 가락시장 인근 물류시설은 제안 명칭을 임시 채택했습니다. 마커로 위치 정보만 확인한 다음 **이동하기**를 눌러야 이동합니다.
4. 이동 후 현장 관찰 / 배분 구역 접근 / 돌아가기 중 선택합니다. 관찰이나 철수만으로 동림을 만나지 않으며 재방문할 수 있습니다. 제보 장소는 일반 파밍을 제공하지 않습니다.
5. 도착 시각이 밤이면 대기줄 흔적·안내문만 읽고 돌아갈 수 있습니다. 낮에 접근해야 군중 사건을 시작합니다. 이동의 기존 시간·허기·조우 규칙은 유지합니다.
6. 패닉 중 가방을 놓거나 붙잡는 선택이 있습니다. 어느 쪽이든 구출 → 소멸 흔적 → 동림의 자기소개로 이어집니다. 각 화면은 버튼으로 진행합니다.
7. 첫 만남을 기록하면 같은 현장에서 자유 생존으로 복귀합니다. 자동 귀가·조직 가입·한지우 등장·새 보상은 없습니다. 이후 귀가는 기존 이동·약탈 판정을 사용합니다.

`HasRadio`, `HasHeardSPBroadcast`, `DongrimRescueCompleted`, `HasMetDongrim`은 재사용합니다. 추가 플래그는 `SupplyRumorUnlocked`, `SupplySiteVisited`, `CrowdIncidentStarted`, `CrowdIncidentResolved`, `DongrimContactHintReceived`입니다.

직렬화한 단계는 `None → Observing(선택) → Panic → Rescue → Disappearance → Introduction → Completed`입니다. 일반 행동의 `CanAct`와 사건 내부 진행을 구분합니다. 패닉 이후에는 외출·수색·식사·휴식·시간 경과로 사건을 건너뛸 수 없고, 선택한 결과가 단계 변경과 함께 저장됩니다. 재접속하면 저장된 단계가 화면보다 우선하므로 같은 결과를 중복 적용하지 않습니다.

방송 데이터는 첫 제보 방송과 일반 방송의 서로 다른 ID를 사용합니다. 첫 방송 원문과 정보 카드는 일지에 한 번 기록하며 재청취는 일반 방송입니다. 반전·소멸 공식·이석현의 실체는 새 대본에 넣지 않았습니다. 구조·자기소개 대본의 주인공 이름은 플레이어 닉네임으로 치환합니다(`SurvivalState.Script`). 닉네임이 비어 있을 때만 `ProtagonistScriptName`(안재현)을 사용합니다.

## 임시값과 범위

| 항목 | 현재 값 |
|---|---|
| 장소명·이동 | 가락시장 인근 물류시설 / 이동 2시간 / 일반 수색 없음 |
| 사건 접근 시각 | 기존 낮 기준 06:00 이상~18:00 미만, 도착 시각 기준 |
| 가방을 놓음 | 소지 물자 1단위 손실, 새 부상 없음 |
| 가방을 붙잡음 | 물자 손실 없음, 기본 HP 20에서 방어 보정, 부상 1곳 |
| 강제 사망 방지 | 사건 선택 피해는 현재 HP−1 이하, 장면 진행은 시간 소모 없음 |

새 효과는 `radioStory.TEMP_BALANCE`에 분리했습니다. 라디오와 부르스타 등 보호 물품은 기존 약탈 보호를 따릅니다. 사건 중에는 굶주림의 강제 시간 경과로 죽지 않지만 일반 이동·생존 중 사망 규칙은 유지합니다. 연락 단서는 “내가 아는 사람들이 있다”는 대사와 플래그까지만 구현했습니다. 연락처·거점 위치·조직명·가입 사건은 만들지 않았습니다.

## 기존 저장

기존 파일명 `vanishing-days-v03.json`을 유지하고 내부 `schemaVersion`을 4로 올립니다. 정상적인 v3 저장은 기존 네 장소·물자·시간·난수·닉네임·부상을 보존하고 제보 장소 진행 슬롯만 추가합니다. 라디오를 이미 가지고 있으면 집에서 첫 방송을 들으면 됩니다. 이전에 방송 청취 플래그만 있던 저장도 새 제보 방송을 실제로 들을 수 있습니다. 구버전에서 첫 만남을 이미 완료한 경우에는 완료 상태를 보존해 재연하지 않습니다.

변환은 불러올 때 메모리에서 수행하고 다음 저장부터 v4가 기록됩니다. 백업 방식은 유지합니다. 의약품 풀의 이전 호환 처리도 계속 적용하며 아이템 재지급·기존 파밍 풀 리셋은 하지 않습니다. 아주 초기의 HP 85 저장인 `vanishing-days-v1.json`은 기존 정책대로 변환 대상에서 제외합니다.
