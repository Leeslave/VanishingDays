# 제작 화면과 생존 크래프팅

하단 문·정비와 메뉴의 보안 진입을 **제작**으로 통합했다. 음식·무기·생활용품 탭을 고정하고 각 목록을 스크롤한다. 제작 뒤에도 탭과 목록 위치를 유지하며, 날짜 기록 화면을 거쳐도 제작 화면으로 돌아온다.

## 음식

기존 밥·스팸밥·참치밥·라면의 조리와 식사를 음식 탭으로 옮겼다. 집 창고의 재료·조리 도구를 사용하며 기존 난이도별 물 소비 규칙을 유지한다.

## 무기

하위 무기를 재료로 상위 무기를 만드는 자체 조합이다. [SKYHILL의 무기 제작·탐색 중심 소개](https://store.steampowered.com/app/382140/SKYHILL/)를 참고했으며 조합과 수치는 이 게임용 임시 설계다.

| 무기 | 힘 | 조합 계열 |
|---|---:|---|
| 나무 곤봉 | 2 | 기초, 곤봉·창의 재료 |
| 헝겊 곤봉 | 4 | 나무 곤봉 강화 |
| 못 박힌 방망이 | 6 | 헝겊 곤봉 강화 |
| 쇠파이프 곤봉 | 4 | 고철 계열 기초 |
| 고철 창 | 5 | 나무 곤봉 파생 |
| 손잡이 칼날 | 7 | 작업대 필요 |
| 간이 도끼 | 8 | 고철 창 강화, 작업대 필요 |
| 보강 칼날 | 10 | 손잡이 칼날 강화, 작업대 필요 |

완성품은 집에 보관한다. 물품 화면에서 장착하며 무기는 한 번에 하나만 적용한다. 교체한 무기는 집에서는 집 창고, 외부에서는 소지품으로 돌아간다. 장착 중인 무기를 제작 재료로 자동 소비하지 않으므로 먼저 벗어 보관해야 한다. 모든 제작 무기는 기존 저항·탈출 보정과 무기 저항의 사망/정신력 결과에 연결한다.

## 생활용품

- 기존 문 강화 1~3단계와 아날로그·전자식 보안을 유지한다.
- **작업대**: 고급 칼날·도끼 조합 해금.
- **간이 정수기**: 혼탁한 물 1병을 1시간 동안 생수 1병으로 정수.
- **집수통**: 3시간 작업으로 혼탁한 물 1병 회수. 정수 후 식수로 사용한다.
- **보강 침구**: 수면 중 졸림 감소 12→16/시간, 6시간 초과 수면의 정신력 회복 2→3/시간. 영구 정신력 상한은 복구하지 않는다.
- **붕대 만들기**: 헝겊·접착테이프로 기존 치료용 붕대 제작.

설비는 한 번 설치하며 중복 설치로 시간·재료를 소비하지 않는다. 정수·물 회수·붕대는 반복 작업이다. 재료는 집 창고에서 사용하고, 제작 시간 동안 허기·식수·수면·날짜 흐름을 그대로 적용한다. 작업 도중 HP가 0이 되면 결과물을 지급하지 않으며 이미 사용한 재료는 반환하지 않는다.

새 재료는 고철·헝겊·끈·접착테이프·혼탁한 물이며 기존 장소의 유한 수색 풀에 추가했다. 지도에는 남은 품목을 노출하지 않는다. 스키마 12 변환은 새 재료 종류만 추가하고 기존 음식·물·목재·도구의 소진 상태, 문 강화, 일기·방송·동행·정신력·갈증을 유지한다. 새 버전에서 소진한 재료는 재접속 시 복구되지 않는다.

## 검증과 파일

`CraftingChecks`의 112개 검증으로 전체 조합·정확한 재료 차감·시설 조건·중복 설치·장비 교체·정수·침구·사망·행동 잠금·구버전 저장을 확인했다. 기존 생존·스토리·물·일기 검증도 통과했다.

`-vdCraft` 실제 플레이어에서 3탭, 음식 조리, 곤봉→헝겊 곤봉→방망이, 장착과 교체, 작업대·정수기·집수통, 물 회수·정수, 침구, 문 강화, 일기 뒤 탭 복원과 자동 저장을 실행했다. 캡처와 실행 로그는 `Builds/CraftingVerification/` 및 `Builds/CraftingPlayerUI.log`에 있다.

주요 소스는 `Assets/Resources/Survival/Crafting.json`, `Assets/Scripts/Survival/Crafting.cs`, `Assets/Scripts/VanishingDaysGame.cs`, `Assets/Scripts/SurvivalState.cs`, `Assets/Scripts/Survival/SessionSaveStore.cs`, `Assets/Scripts/Survival/SleepAndStreetTrade.cs`다. 조합 비용·시간·힘·설비 효과는 조정 가능한 프로토타입 값이다.
