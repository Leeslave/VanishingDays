# 첫 생존 안내와 옆집 첫 인사

새 기록은 오프닝을 마친 뒤 생존 안내에서 시작한다. 기본 조작을 설명하는 첫 화면 다음에 다섯 단계를 안내한다.

1. 옆집 안부 화면에서 **그릇을 돌려드린다**를 눌러 노인과 실제 첫 인사를 나눈다.
2. 식수 관리 화면에서 생활용수 수집·끓이기·직접 음수 방법을 확인한다. 쉬움은 물 무제한임을 안내한다.
3. 물품에서 집 창고와 가방, 수량과 챙기기를 확인한다.
4. 지도에서 목적지 선택과 이동·수색 방법을 확인한다.
5. 수면 화면에서 2·6·8시간 수면, 08시 평가와 하루 기록을 확인한다.

각 화면에서 하단 **생존 안내로 돌아가기**로 복귀한 뒤 **확인했어요 · 다음 안내**를 누른다. 1단계는 실제 첫 인사 후, 나머지는 해당 화면을 열어본 뒤 다음 안내가 활성화된다. 물 생산·이동·수면을 강제로 실행하지 않는다. 안내 자체는 시간·난수·체력·물품을 소모하지 않는다. 실제 생존 행동의 원래 비용은 유지한다.

생활 화면에 현재 안내 단계와 접근 버튼을 표시한다. **안내 건너뛰기**와 메뉴의 **처음 생존 안내 / 생존 안내 이어 보기**를 제공한다. 완료한 첫 인사는 다시 보기로 초기화하지 않는다. 사건·조우·사망·일기·아침 수신 등 기존 우선 화면은 안내보다 우선한다.

## 기존 기록과 노인 첫 안내

기존 기록에는 전체 튜토리얼을 강제로 시작하지 않는다. 노인과 아직 인사하지 않은 기록을 불러온 뒤, 집에서 행동 가능한 때 **벽 너머의 인기척** 안내를 한 번 표시한다. **옆집 안부를 물어본다**는 첫 만남 화면을 열며, 실제 만남은 플레이어가 그릇 반환 버튼을 눌러 진행한다. **지금은 생활부터 정리한다**로 미뤄도 이 안내는 다시 뜨지 않는다. 생활 화면의 **옆집 안부 · 첫 인사**는 계속 사용할 수 있다.

튜토리얼을 건너뛴 새 기록에서도 노인 첫 안내를 한 번 제공한다. 이미 노인을 만난 기록에서는 첫 방문 안내를 생략한다. 날짜별 인사·세 번째 안부의 무응답·문 앞 확인 이벤트는 기존 흐름을 유지한다.

## 저장과 검증

스키마 12에 호환 필드 `OnboardingVersion`, `TutorialActive`, `TutorialStep`, `TutorialViewed`, `NeighborIntroductionSeen`을 추가한다. 이전 저장에서 한 번 초기화하며 물품·진행·체력·난수는 보존한다. 중간 저장을 이어 읽으면 안내 단계와 열어본 화면 상태를 복원한다. 잘못된 단계·비트 값은 저장 검증에서 거절한다.

`Vanishing Days/Validate tutorial and neighbor introduction`에서 세 난이도, 첫 인사 실제 실행, 설명 확인 조건, 저장·재개, 완료·건너뛰기·다시 보기, 기존 기록 보존과 잘못된 저장 거절을 검증한다. 검증용 플레이어 `-vdTutorial`은 실제 버튼 경로와 화면 캡처를 확인한다.

게임 규칙·오프닝 모델 검증 총 867개 통과(이번 안내 검증 80개 포함). `Builds/TutorialPlayerUIFinal.log`의 `VD_TUTORIAL_UI_OK`로 다섯 화면의 실제 버튼·노인 인사·저장 복원·일회성 안내·건너뛰기를 확인했다. 화면 캡처는 `Builds/TutorialVerification/`에 있다.

`-vdSmoke -vdOpeningOnly` 전용 실행에서 실제 오프닝·이름 입력·튜토리얼 진입·건너뛰기·첫 노인 방문 안내·닉네임 저장 연결을 확인했다(`Builds/TutorialOpeningOnlyUI.log`, `VD_TUTORIAL_OPENING_UI_OK`).

일반 Windows와 WebGL 빌드를 갱신했으며, 웹 배포 소스 `sites/vanishing-days-web/dist`에 새 파일을 반영하고 gzip 해제·WebAssembly·브라우저 저장 설정을 확인했다. 실서버에는 게시하지 않았다.
