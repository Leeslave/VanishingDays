# 하루 기록과 첫 동행 탐사 · 구현 기록

적용 범위는 [전달 기획서](StoryDesign-v1.md)의 1~2차다. 기존 `feature/GameConcept`의 `8bc2910`과 생존·첫 만남 대본을 기준으로 작업했으며 기존 프로젝트 설정 변경은 보존했다.

## 플레이 흐름

- 집의 **옆집 안부**에서 그릇을 돌려주고 벽을 두 번 두드리는 일상을 시작한다. 하루에 한 번 안부를 나누며, 답이 없는 사건은 문 앞에서 직접 확인한다. 답이 없다고 사망·소멸로 판정하지 않는다.
- 자정에 전날의 기록지를 확정한다. 행동이 끝나고 필수 사건이 정리된 뒤 읽으며, 외부에서도 열람한다. 긴 수면은 날짜별로 시간을 나누어 기록한다.
- 라디오 확보 후 아침 08:00에 소식을 준비한다. 미청취 첫 방송은 기존 가락시장 제보이며, 읽어야 제보 장소가 열린다. 이후 아침에는 가락시장 완료 전에도 정규 소식을 받는다.
- 라디오가 집에 있으면 외출 중 원격 수신할 수 없다. 휴대한 라디오는 외부에서 사용할 수 있다. 날짜별 수신함에서 골라 읽고 나머지는 보관할 수 있다. 보관한 뉴스가 자정에 재출현하지 않으며 다음 아침 새 호가 준비될 때 다시 알린다.
- 동림의 세 번째 만남 이후, 다음 날부터 낮에 학교에서 첫 동행을 의논한다. 지우는 동행의 위험과 귀환 책임을 묻는다.
- 대화 후 직접 자취방에 돌아가 준비하고, 약속 날짜 이후 낮에 학교에서 재합류한다. 조리 식사를 실제로 소지했다면 1개를 나누지만, 식사가 없으면 짧은 경로로 진행할 수 있다. 날짜를 놓쳐도 재방문 가능하다.
- 탐사 → 철수/입구 추가 확인 → 귀환 보고 → 해산 후 직접 집으로 돌아간다. 집·창고·조리·수면·문 정비는 기존 자취방에 유지된다.

## 기록과 저장

`DailyFact`는 행동의 실제 발생 시점에 생성한다. 획득 결과, 손실, 부상, 식사·조리, 수면, 이웃, 동행을 구분한다. 보관 버튼 클릭은 서사 사건으로 기록하지 않는다. 자정을 넘는 수색의 획득은 완료한 날짜에만 반영하고 전날에는 수색 시작만 남긴다. 완성된 일기는 문장과 작성자를 저장하므로 다시 읽어도 변하지 않는다. 행동 로그 문자열을 분석하거나 런타임 생성형 AI를 호출하지 않는다.

화면 우선순위는 사망 → 길거리/군중/재회/동행의 필수 사건 → 전날 일기 → 수신 가능한 아침 소식 → 원래 생활 화면이다. 열람은 시간·물자·난수를 쓰지 않는다. 미청취 방송은 수신함에 쌓이며 한 화면에서 날짜를 선택할 수 있다.

저장 스키마 11은 구버전 물자·체력·정신력·갈증·수면·난수·동림 재회·해금·기존 50곳 소멸 수신 기록을 유지한다. 옛 미확인 소식은 기존 수신함으로 옮기고 새로 추첨하지 않는다. 도입 전 상세 행동을 알 수 없으므로 과거 일기를 만들지 않고 현재 날짜부터 추적한다. 도입 당일은 그 이후 확인한 일만 포함한다고 표시한다. 기존 가입 플래그를 지우거나 동행 증거로 재사용하지 않는다.

## 대본과 임시 수치

`LifeStory.json`은 기획서의 의도를 반영한 이번 단계의 **신규 대본 초안**이다. 승인된 오프닝·가락시장 대본은 교체하지 않았다. 기존 동림의 세 번째 재회 결과와 주민회관 설명은 분산 연락 장소라는 방향에 맞췄다.

임시 구현값: 안부 1일 1회, 세 번째 안부에 답 없는 사건, 직접 확인 1시간, 준비 다음 날부터 재합류, 탐사 2시간, 철수 1시간/입구 확인 2시간, 실제 소지 식사 1개 소비, 준비 신뢰 +1/철수 신뢰 +2. 조직 전체 인원, 소멸 판정 공식, 전투 보정, 최종 엔딩 조건을 확정한 수치가 아니다. 동행의 물품 보상과 새 전투 확률은 추가하지 않았다.

## 검증

Unity 메뉴 **Validate daily life and first expedition** 및 **Validate game rules**로 모델 검증을 실행한다. 날짜 경계·긴 행동·허위 사실 방지·수신 접근·중복 방지·미청취 보관·일기/탐사 복원·식사 없는 진행·두 선택·기존 뉴스와 가입 플래그 보존을 검사한다.

`BuildUIVerification` 검증 플레이어의 `-vdLife`로 실제 일기→첫 아침→가락시장 전 정규 소식, 노인 첫 만남, 지우 대화, 탐사 선택 저장·복원, 해산과 자취방 귀환, 사망 우선 화면을 실행했다. 스크린샷은 `Builds/DailyLifeVerification/`에 있다. 주 경로는 실제 플레이어로 확인했으며, 여러 날 수신함의 경계·선택 없는 식사 대안·기존 저장 조합은 자동 모델 검증으로 확인한다.

## 다음 연결 지점

첫 동행 완료 후 기존 개인 탐색·동림 순찰·생활을 계속한다. 3~4차의 분산 배식, 거짓 물자 제보, 이석현, SP 기지국, 마지막 안부와 엔딩은 아직 구현하지 않았다. 노인의 후반 이주, 지우 직책, 소멸 임계값·관계 판정, 후반 대본·플레이 길이는 미정이다. 50곳 방송은 서사 제보이며 탐색 지형을 삭제하는 소멸 알고리즘과 별개다.
