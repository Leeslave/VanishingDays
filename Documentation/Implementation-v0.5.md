# v0.5 — 다시 만날 사람과 넓어지는 지도

첫 만남의 “다음에 얘기하지”를 재회 약속으로 이어 간다. 두 번째 만남에서 소멸로 끊기는 골목을 함께 확인하고 집의 문을 보강할 철물점 길을 받는다. 세 번째 만남에서는 동림이 생존자들과 연락하고 있다는 단서를 듣고 주민회관 지하의 식량 창고로 가는 길을 받는다. 조직 가입·새 주요 인물 등 이후 스토리를 강제하지 않는다.

## 진행

| 단계 | 조건 | 결과 |
| --- | --- | --- |
| 시작 | 새 기록 | 집·편의점 |
| 골목 발견 | 편의점 수색 1회 | 빈집 해금 |
| 학교 길 | 빈집 수색 1회 | 고등학교 해금 |
| 납품 메모 | 고등학교 수색 2회 | 약국 해금 |
| 라디오 | 고등학교 수색 3회 후 집에서 수신 | 제보 장소 해금, 기존 군중 사건 |
| 두 번째 만남 | 첫 만남 다음 날부터 낮에 빈집 도착·수색 | 철물점 뒷창고, 학교 재회 약속 |
| 세 번째 만남 | 두 번째 만남 다음 날부터 낮에 학교 도착·수색 | 주민회관 지하, 정기 순찰 약속 |
| 순찰 | 마지막 만남으로부터 2일 이상 지난 낮 | 빈집·학교 교대 재회, 소식 또는 식량↔붕대 교환 |

재회는 도착/수색 시 임의의 강도 조우보다 우선한다. 대화 중에는 다른 행동·시간 진행을 막으며 도중 저장·복원이 가능하다. 식량이 없어도 정보 공유 선택으로 진행할 수 있다. 교환은 소지한 참치캔·스팸·라면 순으로 1개를 소비하고 붕대 1개를 받는다. 같은 날 반복 보상이나 이미 끝난 대화의 재실행은 막는다. 대화 선택에는 시간이 들지 않는다.

## 수색과 지도

8개 장소 중 해금한 마커와 목록만 보인다. 목록은 스크롤하며 수색률, 횟수, 잔존/소진 상태를 표시한다. 상세 화면은 스크롤 영역에 품목별 잔량/최초량과 라디오 단서를 표시한다. 미방문 장소는 정확한 잔량을 공개하지 않는다. 라디오는 학교 수색률에 포함한다. 쌀은 100g을 수색 1단위로 계산·획득한다. 물자가 남았으면 100%로 표시하지 않는다.

물자는 자동 재생성하지 않는다. 소진된 장소의 수색은 시간·난수·강도 조우를 발생시키지 않는다. 동림의 재회 약속은 소진 상태와 별개이므로 빈집과 학교를 다시 찾을 이유가 남는다.

## 문과 보안

라디오 획득 후에도 집의 하단 `문·정비` 버튼을 유지한다. 보안 화면은 스크롤하며 문 3단계와 기존 설비를 모두 표시한다.

| 문 | 집 재료 | 시간 | 추가 침입 저항 |
| --- | --- | --- | --- |
| 빗장 | 목재 2·생활도구 1 | 1시간 | 1 |
| 문틀 | 목재 3·생활도구 2 | 2시간 | 2 |
| 이중 잠금 | 목재 4·생활도구 3 | 3시간 | 3 |

이전 단계를 먼저 설치해야 한다. 설치 완료 시 중복 소비하지 않는다. 문 자체의 외부 주목도는 0이며, 기존 디지털 설비의 주목도와 침입 위험 계산은 유지한다. 비용·발견 횟수·재회 간격·새 장소의 물량은 TEMP_BALANCE 제안값이다.

## 저장

파일명 `vanishing-days-v03.json`을 유지하고 내부 버전을 5로 올린다. v3 → v4 → v5 변환으로 기존 풀의 소진량, 장비, 기존 보안, 첫 만남과 군중 선택을 보존한다. 추가 장소만 최초 물자 풀을 만든다. 예전 기록의 빈집·학교는 유지하며, 이미 동림을 만났다면 불러온 날 낮에 빈집에서 재회를 시작할 수 있다. 새 버전은 해금·방문·동림 만남 횟수·마지막 만남 날짜·대기 중 재회를 저장하고 검증한다.

## 검증

`WorldProgressionChecks`는 실제 저장 왕복과 v4 이관을 포함해 단계별 길, 소진 잔량, 라디오 진행률, 재회 시간·장소·선택 잠금, 교환 자원 보존, 중복 방지, 순찰 간격, 문 비용·저항을 확인한다. 기존 생존·라디오·오프닝 검사도 빌드 전에 실행한다.

UI 검증 빌드는 초기 2개 장소에서 8개 장소로 확장, 실제 버튼으로 재회 2회와 정기 순찰, 소진 장소 재방문, 문 3단계 보강을 실행하고 화면을 캡처한다. 일반 빌드에는 자동 진행 코드를 포함하지 않는다.
