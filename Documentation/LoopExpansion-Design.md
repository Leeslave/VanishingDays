## 3. 요청 (2막~)

### 들어오는 곳
- 아침 라디오 (SP 방송의 지역 소식 끝부분)
- 동림 순찰 재회 (지금의 식량↔붕대 교환 자리)
- 주민회관 (영숙, 지우)
- 옆집 노인 → 이사 후 약국 위층

### 종류 [제안]
| 종류 | 예 | 하는 일 |
|---|---|---|
| 전달 | 약국에서 소독약을 주민회관에 | 물건을 들고 장소 이동 |
| 안부 확인 | 사흘째 배식에 안 온 사람의 거처 | 장소에 가서 확인. 결과는 무사·부재·소멸 흔적 중 하나 |
| 수배 | 끈 3개가 필요하다 | 수색·제작으로 구해서 전달 |
| 소식 확인 | 방송에 나온 장소가 정말 열려 있는지 | 가서 보고 돌아와 알림 |

### 규칙 [제안]
- 하루 1~2개. 1~2일 안에 하지 않으면 조용히 사라진다. 놓쳤다고 벌을 주지 않고, 그 사람과의 짧은 후속 대사만 달라진다.
- 보상: 신뢰(`LateTrust`) +1이 기본. 신뢰는 3막 지원 인력(0~2명)으로 이어진다. 가끔 새 장소나 소식, 아주 가끔 소량의 물자.
- 글은 틀(장소·사람·물건을 바꿔 끼우는 문장) 위주에, 이야기와 이어지는 손으로 쓴 요청을 막마다 몇 개 섞는다.
- 3막 동안은 일반 요청을 멈추고 「끊어진 길」 관련 무전만 들어온다.
- 4막부터는 요청이 거점 요청으로 바뀌어 운영 화면에 들어간다.

## 4. 동네 지도 영구 소멸과 막 전환

### 정해진 소멸 [제안]

| 막 | 사라지는 것 | 연결되는 장면 |
|---|---|---|
| 1막 | 가락시장 일부 (지금 구현) | 군중 사건 직후 |
| 2막 | 배식에 오지 않은 사람의 거처 | `absent_share` 뒤 확인 요청 |
| 3막 | 교신하던 거점 1곳 | `post_vanished` (정상 교신 직후) |
| 3막 | 성내천 보행교 가운데 | 「끊어진 길」 시작 |
| 4막 | 거점 또는 경로 1~2곳 | 운영 중 사건 |
| 5막 | 장소 몇 곳 | 서울은 계속 사라진다 |

- 이야기 진행에 필요한 장소는 그 막에서의 역할이 끝난 뒤에만 사라진다.
- 플레이어가 그 장소 안에 있을 때는 일어나지 않는다.
- 사라진 장소는 지도에서 빈 자리로 남고, 사라진 날짜가 기록된다. 남아 있던 수색 물자도 함께 사라진다.
- 전국 소멸 속보는 지금처럼 따로 유지한다. 동네 소멸은 속보에 나오지 않을 수도 있다(이웃이 알아차리지 못하는 것 자체가 주제).

### 반례 [제안]
- 전조(백색 침묵, 주파수 이상, 경계선 탈색)는 여러 번 나오지만 실제 소멸로 이어지는 것은 일부다. 예: 전조 3번 중 1번.
- 반대로 전조 없이 사라지는 경우, 정상 교신 직후 사라지는 경우를 반드시 하나 이상 둔다.
- 이 비율은 고정 규칙으로 보이지 않도록 막마다 다르게 배치한다.

### 막 전환
- 막 전환에는 사건 완료만 요구한다. 목표 날짜와 장면별 대기 시간은 [5막 재배치표](StoryRestructure-v2.md)를 따른다.

## 5. 거점 설비 제작 (4막)

기존 제작 화면에 "거점 설비" 분류를 더한다. 집 설비(정수기, 집수통)를 만드는 방식과 같다.

| 설비 [제안] | 재료 (임시) | 효과 |
|---|---|---|
| 거점 정수기 | 기존 간이 정수기 레시피 재사용 | 그 거점의 물자가 떨어지는 속도 절반 |
| 간이 안테나 | 고철 4, 끈 2, 생활도구 1 | 그 거점의 교신이 떨어지는 속도 절반. **큰 자재** |
| 저장 선반 | 목재 4, 생활도구 1 | 그 거점의 물자 상한 +1단계 |

- 설치는 재현이 낮에 직접 들고 가서 한다. 아침 결정 2개를 쓰지 않는다.
- 큰 자재 규칙(한 번 이동에 1개, 인력 1명당 +1)은 「끊어진 길」과 같은 것을 다시 쓴다.

## 6. 기존 요소 정리 [제안]

| 요소 | 처리 |
|---|---|
| 전국 소멸 속보 | 1~3막 유지. 4막에는 운영 화면 아침에 합침 |
| 길거리 행상인 | 유지. 2막부터 주민회관 교환소가 더해짐 |
| 굶주린 사람 조우, 위협과 무기 공격 | 무기 장착 시 위협 또는 공격. 2막의 일부 조우에서는 거점을 안내할 수 있다. |
| 집 약탈·보안 | 유지. 4막에는 자취방도 거점이므로 보안이 자취방 거점 상태와 이어짐 |
| 수면·정신력 | 유지. 영숙 실종, 동림 사망, 거점 소멸 같은 사건이 정신력에 남도록 연결 |

## 7. 구현 순서

### 1단계 — 3막 세로 구간 [구현됨 2026-11-08]

> 구현 결과와 설계와 다르게 한 점(스키마 버전 대신 업그레이드 함수, 고립 보호소는 무전으로만)은 [3막 구현 기록](Act3-BrokenPath-Implementation.md)에 있다.

목표: 핵심 선택부터 「끊어진 길」 결과까지 세 경로를 처음부터 끝까지 플레이할 수 있게 한다. 이 단계에서는 앞 이야기와 연결하지 않고, **에디터에서 3막 시작 상태로 바로 들어가는 테스트 진입**으로 확인한다.

| 작업 | 내용 |
|---|---|
| 플래그 저장 | `CoreChoice`, `RescueOutcome`, `DonglimAlive`, `YeongsukState` 등. 저장 스키마 버전 올림 |
| 장소 3곳 | 공사 현장, 성내천 보행교, 고립 보호소 |
| 아이템·제작 | 사다리, 강철 발판, 고정 벨트, 로프(제작), 들것(제작) |
| 큰 자재 운반 | 한 번 이동에 1개, 인력 1명당 +1, 현장에 내려놓기 |
| 장면 | `core_choice` → 현장 조사 → 계획 비교 → 시공 → 철수 → 결과(A-1 / A-2 / B_Light / B_Heavy, 석현 결별, 영숙 빈자리) |
| 건너편 상태 | 버팀 → 흔들림 → 위급, 무전 문구 |
| 검사 | 기존 `LateStoryChecks`처럼 편집기 검사 추가 |

완료 기준: 네 가지 결과를 각각 끝까지 통과, 각 단계 중간에 저장 후 불러오면 그대로 이어짐.

### 2단계 — 이야기 뼈대 재배치 [구현]
- 막 구조와 막 전환 조건
- 동네 지도 영구 소멸 (정해진 소멸 + 반례)
- 기존 `LateStory` 장면을 재배치표대로 이동·수정 (기준본과 충돌하는 문장 3곳 포함)
- 1단계 세로 구간을 실제 진행 흐름에 연결

### 3단계 — 2막 채우기 [구현]
- 요청 시스템
- 영숙·석현 관련 신규 장면, 동림·석현 동창 재회
- 공사 현장을 2막에 미리 열기

### 4단계 — 4막 [임시 구현]
- 연락망 운영 화면, 방송 방침, 거점 설비
- 지우의 두 갈래 (성장 / 폭주)

### 5단계 — 5막과 엔딩 [임시 구현]
- 엔딩 조건 정리, COLLAPSE 엔딩, EXP-01 관측 기록 이스터에그
- 구조 거점의 유한 파밍을 추가했다. 전체 난이도·물자 흐름은 완주 플레이로 추가 조정할 수 있다.
