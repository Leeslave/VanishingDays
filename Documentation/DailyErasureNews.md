# 날짜별 전국 소멸 속보

현재 방송 시각·수신 접근·수신함 규칙은 [하루 기록·동행 구현 기록](DailyLife-Implementation.md)을 따른다. 아래는 최초 도입 당시의 기록이며, 현재는 자정에 일기를 만들고 아침 08:00에 소식을 준비한다. 가락시장 완료는 정규 소식의 선행 조건이 아니다.

라디오를 소지하고 가락시장 군중 사건을 완료한 뒤부터 자정의 날짜 전환마다 새 소멸 제보 한 건을 정한다. 사건을 완료한 당일에는 생성하지 않는다. 이동·휴식 등 행동을 마친 뒤 속보를 보여주며, 먼저 처리할 조우나 스토리 선택이 있다면 그 뒤에 표시한다. 여러 날짜를 넘긴 경우 미확인 속보를 날짜순으로 읽는다. 읽기와 지도 열기에는 시간이 들지 않는다.

원고는 `Assets/Resources/Survival/ErasureNews.json`에 50곳을 둔다. 서울 20곳은 임시 밀집 대피소 10곳과 사람들이 떠난 빈 건물 10곳이다. 지방 30곳은 강원·충북·충남·전북·전남·경북·경남·제주의 읍 단위 제보다. 지명은 실재하지만 건물·임시 대피소·소멸 사건과 증언은 게임용 창작이다. 기존 탐색 장소를 삭제하거나 소지품을 잃게 하는 기능은 추가하지 않는다.

서울은 강당·체육관·지하 주차장 등 사람을 과밀하게 수용한 대피소, 공장·사무실·공동주택 등 비워진 건물의 소멸로 나뉜다. 지방은 특정 건물 하나가 아니라 읍내·마을·도로가 함께 사라졌다는 원고를 사용한다. 인명 상황은 제보에서 확인되지 않은 상태로 유지한다.

소멸 소식은 별도의 저장 난수를 사용해 조우·약탈 난수 흐름에 영향을 주지 않는다. 한 날짜의 소식은 재추첨하지 않으며 이미 사라진 장소는 후보에서 제외한다. 50곳을 모두 소진한 뒤에는 추가 제보가 없다는 일일 기록을 남긴다. 기존 저장은 수신 내역을 빈 상태로 초기화하고 다음 날짜 전환부터 시작한다. 저장 버전은 7이며 과거 진행과 정신력은 보존한다.

전국 지도는 자체 UI 도형으로 그린 개략도다. 좌표는 대표 위치를 대략적으로 표시하며 행정 경계나 정밀 지도를 의미하지 않는다. 서울 소식은 서울 지점에 모아 표시하고, 지방은 읍별 위치에 표시한다. 선택한 날짜의 표시는 강조하며 원문은 스크롤해 읽을 수 있다. 수신한 지역만 지도와 목록에 나타난다.
