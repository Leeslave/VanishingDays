## 1. 지형 — 성내천 보행교의 가운데 경간 소멸 [제안]

- **장소**: 송파구 성내천을 건너는 보행교. 건너편은 고립 보호소가 있는 블록이다. 차량 교량은 붕괴 심화기에 이미 사라졌고, 이 보행교가 마지막 연결이었다.
- **사건**: 동림이 보호소에서 구조하는 동안 보행교의 가운데 부분이 사라진다. 양쪽 교대와 **가운데 교각 하나**는 남는다. 그래서 끊어진 곳은 하나의 큰 틈이 아니라 교각을 사이에 둔 **짧은 틈 두 개**가 된다.
- **왜 이번엔 이을 수 있는가** (기준본 요구사항): 보통 소멸은 건물이나 구역을 통째로 지운다. 이번에는 경계가 교각 사이를 지나가 다리 일부만 잘려 나갔다. 재현은 이것을 확인하고 기록할 뿐 이유는 알 수 없다. "모든 소멸을 이렇게 이을 수 있다"는 오해를 막도록 동림과 지우가 이 점을 짚는다.
- **아래쪽**: 하천 바닥까지 3~4m. 물은 얕지만 바닥에 잔해가 있어 추락하면 다친다. 내려갔다 올라가는 우회가 가능하지만 느리고, 부상자를 옮기기 어렵다.
- **긴장 요소**: 남은 교각이 버틸지 알 수 없다. 시공 도중 백색 침묵(바람 소리가 끊긴 듯한 전조)이 올 수 있지만 **아무 일도 일어나지 않는 반례**로 쓴다(기준본 §03).

## 2. 시공 방법 세 가지 [제안]

기준본의 "임시 발판 · 간이 가교 · 우회 구조"를 그대로 세 안으로 만든다.

| | 가. 사다리 발판 | 나. 간이 가교 | 다. 하천 바닥 우회 |
|---|---|---|---|
| 방법 | 틈마다 사다리를 눕혀 걸침 | 사다리 + 강철 발판 + 로프 난간 | 양쪽 둑에 사다리를 내리고 하천 바닥으로 건넘 |
| 자재 | 사다리 2 | 사다리 2, 강철 발판 2, 로프 2, 고정 벨트 2 | 사다리 2, 로프 1 |
| 시공 시간 | 2시간 | 6시간 (인력 1명당 -1시간, 최소 3시간) | 1시간 |
| 한 번에 건너는 인원 | 1명씩, 느림 | 여러 명 | 1명씩, 매우 느림 |
| 부상자 이동 | 들것 불가. 업고 건너면 추락 위험 | **들것 가능** | 들것 불가. 로프로 내리고 올림 |
| 철수에 걸리는 시간 | 중간 | 짧음 | 김 |
| 성격 | 빠르지만 위험 | 준비가 많지만 안전 | 자재가 적지만 시간이 듦 |

세 안 모두 정답·오답이 아니다. 가진 시간·자재·인력에 따라 고르는 선택이다.

## 3. 자재와 운반 [제안]

### 새 자재 (3종 + 제작 2종)
| 자재 | 구하는 곳 | 비고 |
|---|---|---|
| 알루미늄 사다리 | 공사 현장(신규), 철물점 뒷창고 1 | **큰 자재** |
| 강철 발판(비계 발판) | 공사 현장(신규) | **큰 자재** |
| 화물 고정 벨트 | 철물점 뒷창고, 공사 현장 | 일반 소지품 |
| 로프 (제작) | 끈 3 + 헝겊 1, 1시간 | 기존 제작 화면 사용 |
| 들것 (제작) | 목재 2 + 헝겊 3 + 끈 2, 2시간 | 가교안의 부상자 이동에 필요 |

- **공사 현장**은 2막에 미리 열리는 수색 장소로 둔다. 2막에 사다리와 발판을 보여 주되 "너무 커서 지금은 들고 갈 이유가 없다"는 문장으로 남겨 둔다. 3막에서 기억이 이어지게 하려는 장치다.

### 운반 규칙
- 지금 소지품에는 무게 제한이 없다. 이 퀘스트에만 **큰 자재** 규칙을 둔다.
- 재현은 한 번 이동할 때 큰 자재를 **1개**만 들 수 있다. 지원 인력 1명이 붙을 때마다 +1.
- 큰 자재는 현장(보행교 이쪽 끝)에 내려놓을 수 있다. 현장에 쌓인 자재는 지도에 표시한다.
- 그래서 가교안은 혼자라면 4번 왕복해야 하고, 인력이 있으면 줄어든다. 인력을 어디에 쓸지가 선택이 된다.

## 4. 진행 순서 (기준본 6단계 대응)

| 단계 | 하는 일 | 사용하는 기존 시스템 |
|---|---|---|
| 1. 현장 조사 | 끊어진 길이, 남은 교각, 건너편 인원·부상자, 우회 가능성 확인. 항목마다 1시간 | 장면 선택지 + 시간 소모 |
| 2. 계획 선택 | 세 안을 카드로 비교. 조사를 건너뛴 항목은 "?"로 표시 | 신규 비교 화면 |
| 3. 자재 확보 | 공사 현장·철물점 수색, 로프·들것 제작, 큰 자재 운반 | 기존 수색·제작·지도 + 운반 규칙 |
| 4. 시공 | 현장에서 시간을 들여 설치. 인력 배치 | 장면 + 시간 소모 |
| 5. 철수 | 부상자 순서, 추가 구조 시도, 철수 판단 → **P0-2 판정이 여기 연결됨** | P0-2에서 정함 |
| 6. 후속 | 결과를 일지·거점·인물 반응에 반영 | 플래그 (`RescueOutcome`, `DonglimAlive` 등) |

무전: 단계마다 동림·지우와 짧은 교신이 들어간다. 동림 쪽 상황(부상자 상태, 남은 식량)이 조금씩 나빠지며 시간 압박을 준다.

## 5. 시간 압박 — 건너편 상태 악화 [확정 방향 / 수치 제안]

고정 마감이나 카운트다운은 두지 않는다(기준본 §03: 남은 시간을 확정값처럼 보여주지 않음). 대신 퀘스트가 시작된 뒤 흐른 시간에 따라 **건너편 상태**가 단계적으로 나빠지고, 무전으로만 전해진다.

| 단계 | 경과 (임시) | 무전으로 들리는 것 | 철수에 주는 영향 |
|---|---|---|---|
| 버팀 | 0~24시간 | 동림이 침착하게 인원·부상자 수를 알림 | 없음 |
| 흔들림 | 24~48시간 | 식량이 떨어짐, 부상자 한 명이 열이 오름 | 부상자 이동에 시간이 더 듦 |
| 위급 | 48시간~ | 교신이 짧아지고 동림 목소리가 갈라짐 | 걸어서 이동 못 하는 부상자 증가, 들것 필요 인원 증가 |

- 단계 경계는 플레이어에게 숫자로 보이지 않는다. 무전 내용으로만 짐작한다.
- 위급 단계에 들어가도 자동 실패는 없다. 철수가 더 어렵고 느려질 뿐이며, 결과 판정은 P0-2에서 정한다.
- 지우는 이 기간 동안 무전을 반복해서 걸어온다(지우의 불안 묘사). 동림 생존 루트에서는 지우가 자재 위치·인력·귀환로 정보를 주는 역할로 바뀐다(기준본 §17).

## 7. 구조 판정 (P0-2, P0-3)

### 결정 기록 (2026-11-08 사용자 결정)

| 항목 | 결정 |
|---|---|
| A 경로 동림 생사 | [확정] **선택으로만 결정.** 확률 판정 없음. 준비가 좋을수록 마지막에 남는 사람이 줄어들 뿐, 0명이 되지는 않음 |
| B 경로 실패 (P0-3) | [확정] **중상으로 생환.** B에서 동림은 죽지 않음. 진엔딩 전제 유지 |
| 구조를 미루거나 방치할 때 | [확정] **끝까지 대기.** 자동 해결·자동 사망 없음. 기다리는 동안 이름 없는 구조 대상만 줄어듦 |
| 지원 인력 | [확정] **2막 관계로만** 0~2명. 경로(A/B)와 무관 |

### 7-1. 준비도 (플레이어에게 숨김)

철수 결과를 정하는 내부 점수. 숫자는 화면에 보이지 않고, 무전과 현장 묘사로만 짐작할 수 있다.

| 요소 | 점수 (임시) |
|---|---|
| 시공 방법 | 간이 가교 +2 / 사다리 발판 +1 / 하천 바닥 우회 0 |
| 들것 | 있음 +1 |
| 지원 인력 | 2명 +1 (0~1명은 0) |
| 철수 시작 시점의 건너편 상태 | 버팀 +1 / 흔들림 0 / 위급 -1 |

범위는 -1 ~ 5.

### 7-2. 지원 인력 — 2막 관계

- 2막에서 쌓인 신뢰(현재 `LateTrust`, 첫 동행의 `CompanionTrust` 포함)로 정한다. 임시 기준: 3 이상 1명, 6 이상 2명.
- 인력은 주민회관·해방전선에서 재현을 믿고 따라오는 사람들이다. A·B 어느 쪽을 골랐는지와 관계없다.
- 0명이어도 퀘스트는 진행된다. 큰 자재를 혼자 여러 번 나르고 시공이 길어질 뿐이다.

### 7-3. A 경로 (동림 지지)

1. 시공을 마치면 건너편 사람들이 먼저 건너온다. **영숙은 첫 무리에 포함되어 구조된다** [제안].
2. 준비도에 따라 **마지막에 남는 사람** 수가 정해진다.

   | 준비도 | 남은 사람 (임시) |
   |---|---|
   | 0 이하 | 4명 |
   | 1 | 3명 |
   | 2~3 | 2명 |
   | 4 이상 | 1명 |

3. 마지막 장면: 동림이 "안에 아직 사람이 있어, 다시 들어갈게"라고 한다.
   - **퇴로를 지킨다 → A-2.** 동림 생환. 남은 사람은 구하지 못한다. 이후 석현과 결별.
   - **다시 들여보낸다 → A-1.** 동림 사망. 남은 사람 가운데 1명을 뺀 나머지를 구한다(최소 1명). 지우 폭주 갈래로 이어짐.
4. A-1의 죽음은 "위험한 재진입과 후퇴 지연" 때문으로만 그린다. 전조를 못 읽었다거나 벌을 받았다는 설명은 붙이지 않는다(기준본 §16).

### 7-4. B 경로 (석현 지지)

1. 제한적 구조가 이미 진행됐고, **영숙은 소멸한 건물에 남아 실종** 상태다(기준본 §13). 철수 뒤에 확인된다.
2. 동림은 혼자, 또는 적은 인원과 함께 고립되어 있다. A와 같은 "다시 들어간다" 선택은 없다.
3. 준비도에 따라 동림의 상태가 정해진다.
   - 준비도 2 이상: **경상 생환.** 4막에서 그대로 현장 구조를 맡는다.
   - 준비도 1 이하: **중상 생환.** 4막에서 현장 구조가 제한되고, 지우의 불안이 커진다. 진엔딩 조건은 유지된다.
4. 함께 고립된 사람들의 생존 인원도 준비도에 따라 줄어든다(A의 남은 사람 표를 그대로 사용).

### 7-5. 방치할 때

- 건너편이 위급 단계에 들어간 뒤로는 **하루가 지날 때마다 이름 없는 구조 대상이 1명씩 줄어든다**(동림·영숙 같은 이름 있는 인물은 줄지 않음).
- 동림이 스스로 건너오거나 죽는 자동 결말은 없다. 이야기의 다음 장면은 구조가 끝날 때까지 열리지 않고, 생존 루프만 이어진다.
- 지우가 매일 무전을 건다. 미룬 날수만큼 `JiuControlState`의 불안이 쌓여 4막에 반영된다 [제안].
