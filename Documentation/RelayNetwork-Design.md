## 2. 지켜야 할 원칙

- 분산 운영은 소멸을 막지 않는다. 얻는 것은 대피·연락·복구 능력이다(기준본 §22).
- 거점 상태는 **말로** 보여준다(예: "수용 여유 있음", "교신 불안정"). 소멸 위험도나 남은 시간은 어디에도 표시하지 않는다.
- SP 기지국은 운영 도구일 뿐 예언 장치가 아니다. 기지국에서 얻는 것은 방송 송출, 갱신된 원고, 불완전한 지역 자료뿐이다.

## 3. 거점과 경로

### 거점 (4막 시작 기준) [제안]

| 거점 | 역할 | 경로별 차이 |
|---|---|---|
| 자취방 | 재현의 생활 거점, 물자 창고 | 공통 |
| 주민회관 | 배식·교환 | A: 영숙이 배식을 맡음 / B: 영숙의 빈자리 |
| 약국 위층 | 노인. 흰 수건으로 안부 표시 | 공통. `NeighborCheck`와 연결 |
| 중계 거점 (옛 방송 중계실) | 교신 중계 | B: 석현이 자료 검증 담당 / A: 석현이 떠난 빈 중계실 |
| 성내천 건너편 거점 | 「끊어진 길」에서 구조한 사람들 | A: 인원 많음 / B: 인원 적음 |
| SP 기지국 | 방송 송출. 운영 화면을 여는 곳 | 사람이 사는 거점이 아님 |

### 거점 상태 (화면에는 말로, 내부는 0~3)

| 항목 | 표시 |
|---|---|
| 수용 | 여유 / 빠듯 / 가득 |
| 물자 | 넉넉 / 부족 / 바닥 |
| 교신 | 정상 / 불안정 / 두절 |
| 담당자 | 이름 또는 "없음" |

### 경로
거점 사이의 선. 열림 / 위험 / 끊김. 소멸로 끊길 수 있고, 끊긴 경로로는 물자를 보낼 수 없다.

## 4. 하루 흐름

1. **아침 08:00** — 기존 소멸 속보 시간과 같다. 운영 화면이 열리고, 오늘 들어온 제보와 요청 2~3개가 보인다. 일부는 출처 미상이다.
2. **오늘의 결정 2개** — 아래 네 종류 중에서 고른다.
3. **방송 송출** — 고른 내용이 아침 방송이 된다.
4. **낮** — 평소처럼 자유롭게 행동한다. 거점에 직접 가면 결정을 쓰지 않고도 상태를 확인할 수 있고, 물자를 들고 가서 전할 수도 있다.
5. **밤** — 거점 상태가 바뀌고, 다음 아침 운영 화면에 반영된다.

### 결정 종류

| 결정 | 하는 일 | 비고 |
|---|---|---|
| 안내 방송 | 거점 하나를 골라 확인된 경로·수용 여부·이동 시각을 전함 | 분산 방침의 핵심 행동 |
| 담당자 배치 | 지우·동림·석현·구조된 사람·지원 인력을 거점에 배치 | 담당자가 있는 거점은 교신이 유지되고 스스로 판단함 |
| 물자 배분 | 자취방·주민회관의 실제 물품을 거점으로 보냄 | 경로가 열려 있어야 함. 위험 경로면 일부 손실 가능 |
| 확인 요청 | 교신이 두절된 거점에 담당자를 보내 확인 | 재현이 낮에 직접 가면 결정 없이 가능 |

### 물자 배분 수치 [제안]
- 물자 1단계 올리기 = 식량 3개 또는 물 3병 또는 약품 2개 (조합 가능).
- 담당자가 없는 거점은 2일마다 물자 1단계, 교신 1단계가 떨어진다.
- 그래서 "내가 쓸 물자"와 "거점에 보낼 물자" 사이에서 고민하게 된다. 파밍이 4막까지 의미를 갖는 이유다.

## 5. 방송 방침 (4막 초 1회 선택)

`endless` 장면의 선택지 세 개를 이 선택으로 다시 쓴다.

| 방침 | 매일 운영 | 생기는 사건 | 장기 결과 |
|---|---|---|---|
| 검증된 분산 안내 | 결정 2개를 모두 써야 연락망이 유지됨. 일이 많음 | 수용 초과 요청, 경로 변경, 거점끼리의 물자 요청 | `RelayNetwork`↑. 진엔딩 조건 |
| 하나의 안전지대 집결 | 결정이 1개로 줄어듦. 편함 | 집결지 과밀, 운송 병목, 잘못된 안내가 연쇄됨 | `Lure`↑. BAD 엔딩 쪽 |
| 방송 중단·은폐 | 결정이 거의 필요 없음. 조용함 | 고립 거점 증가, 구조 누락, 거짓 제보를 걸러내지 못함 | `RelayNetwork`↓. NORMAL·COLLAPSE 쪽 |

- 4막 중반에 **출처 미상의 집결 제보가 한꺼번에 들어오는 사건**을 둔다 [제안]. 분산 방침을 골랐어도 이때 "한곳에 모이라고 방송한다"는 선택지가 나온다. BAD 엔딩으로 가는 유혹이자, 기존 `Lure` 수치와 이어지는 지점이다.

## 6. 경로·인물에 따른 차이

| 조건 | 운영에 미치는 영향 |
|---|---|
| B (석현 협력) | 출처 미상 제보 옆에 석현의 **대조 메모**가 붙는다("지난 방송과 문장 구조가 같음" 같은 근거). 진짜인지 확정하지는 않는다 |
| A (석현 없음) | 대조 메모가 없다. 제보의 진위는 재현이 낮에 직접 가서 확인해야 한다 |
| 동림 생존 (A-2, B_Light) | 현장 담당. 두절된 거점 확인을 맡길 수 있다 |
| 동림 중상 (B_Heavy) | 현장 담당 불가. 교신 담당만 가능 |
| 동림 사망 (A-1) | 지우를 담당자로 두면 **일부 요청을 숨긴다**(운영 화면에 뜨지 않음). 재현이 그 거점에 직접 가야 숨긴 요청을 발견한다. 교신 권한을 다른 사람에게 나눠 주는 결정이 지우 회복 단계를 진행시킨다 (기준본 §17) |
| 지우 성장 루트 (동림 생존) | 지우에게 교신 권한을 넘기면, 지우가 맡은 거점은 결정 없이도 유지된다. 지우의 독립 성장 사건과 연결 (P1-3) |

## 7. 소멸과의 관계

- 4막 동안 소멸이 거점이나 경로를 지울 수 있다. 시나리오상 정해진 소멸 1~2회와, 아무 일도 일어나지 않는 전조 반례를 함께 둔다 [제안].
- 거점이 사라졌을 때의 피해 규모는 **평소에 사람과 물자가 얼마나 나뉘어 있었는지**로 정해진다. 분산이 잘 돼 있었으면 이미 다른 거점에 있던 사람이 많다. 소멸 자체를 막은 것은 아니다.
- 어떤 거점이 왜 사라졌는지는 끝까지 설명하지 않는다.

## 8. 화면 (9:16) [제안]

- 기존 `NeighborhoodMapGraphic` 위에 거점 점과 경로 선을 그린다.
- 상단에 "오늘의 결정 0 / 2"와 방송 방침.
- 점을 누르면 아래에서 상태 시트가 올라온다: 수용·물자·교신·담당자, 그리고 그 거점에 할 수 있는 결정 버튼.
- 결정 2개를 고르면 **방송 송출** 버튼이 활성화된다. 송출 전에는 고른 결정을 취소할 수 있다.

## 9. 결과 플래그 → 엔딩

| 플래그 | 계산 (임시) | 쓰이는 곳 |
|---|---|---|
| `BroadcastPolicy` | Distributed / Gather / Silent | 5막 분위기, BAD 판정 |
| `RelayNetwork` | 교신 정상 거점 수 × 유지 일수 누적 | TRUE / COLLAPSE 판정 |
| `SupplyNetwork` | 물자 바닥이 아닌 거점 수 × 유지 일수 누적 | TRUE / COLLAPSE 판정 |
| `JiuControlState` | 숨긴 요청 수, 권한 이양 횟수 | 지우 결말, BAD 판정 |
| `Lure` | 집결 방송 횟수 (기존 수치 재사용) | BAD 판정 |
| `NeighborCheck` | 약국 위층 확인 횟수 | 5막 마지막 안부 연출 |

엔딩 조건의 구체 수치는 P1-5(SP 방송과 수송이 장기 생존에 미치는 영향)에서 정한다.
