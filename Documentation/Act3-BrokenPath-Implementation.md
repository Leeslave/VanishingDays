# 3막 「끊어진 길」 세로 구간 구현 기록

[루프 확장 설계](LoopExpansion-Design.md) §7 1단계와 [끊어진 길 설계](BrokenPath-Design.md)를 따라, 핵심 선택부터 결과 네 가지까지 한 번에 플레이할 수 있게 만들었다. 앞 이야기와는 아직 연결하지 않았고(2단계), **테스트 진입**으로 3막 시작 상태에 바로 들어간다.

## 흐름

1. **핵심 선택** `core_choice` (B · 장면 대화) — 중계실에서 동림과 석현이 동시에 도움을 청한다.
   - A: 동림의 보호소 구조를 돕는다.
   - B: 석현의 중계 철수를 돕는다.
2. **무전** `path_broken_A/B` (C · 수신 기록) — 보행교 가운데가 끊어져 동림이 건너편에 고립된다. 이때부터 지도에 **공사 현장**과 **성내천 보행교**가 열린다.
3. **현장 작업** (보행교 화면)
   - 조사 4종(각 1시간): 끊어진 길이, 남은 교각, 건너편 상황(무전), 둑 아래 길.
   - **계획 비교**: 방법 세 가지를 카드로 비교한다. 조사하지 않은 항목은 `?`로 남고, 시공 전까지 바꿀 수 있다.
   - **자재 운반**: 공사 현장에서 큰 자재를 들고 보행교에 내려놓는다.
   - **시공**: 계획한 자재가 모두 모이면 시공한다.
4. **철수** `evac_A/B` (B)
   - A 경로는 **퇴로를 지킨다**(A-2) 또는 **다시 들여보낸다**(A-1)를 고른다. 그 뒤 결과 장면과 석현의 결별 `parting`으로 이어진다.
   - B 경로는 준비도에 따라 B_Light 또는 B_Heavy가 되고, 영숙의 빈자리 `empty_ladle`(A · 일지)로 이어진다.
5. 끝나면 단계 4가 되고, 요약이 일지와 결과 문구에 남는다.

시공 도중에는 "바람 소리가 끊겼지만 아무 일도 없었다"는 반례 문단이 매번 들어간다.

## 규칙과 수치 (`Resources/Survival/BrokenPath.json`)

| 항목 | 값 |
|---|---|
| 지원 인력 | 2막 신뢰(LateTrust+CompanionTrust) 3 이상 1명, 6 이상 2명 |
| 큰 자재(사다리·강철 발판) | 한 번에 1개 + 인력 1명당 1개. 소지품 옮기기에도 같은 제한 |
| 작은 자재 | 고정 벨트는 공사 현장에서 한 번에 모두, 로프·들것은 집에서 제작 |
| 건너편 상태 | 무전으로만 전달. 핵심 선택 후 24시간 미만 버팀, 48시간 미만 흔들림, 그 뒤 위급 |
| 방치 | 위급 상태로 날이 바뀔 때마다 이름 없는 1명을 잃음, 최대 3명. 지연 일수는 계속 셈 |
| 준비도 | 방법 점수 + 들것 1 + 인력 2명 1 + 건너편(버팀 +1 / 흔들림 0 / 위급 −1) |
| 남는 인원 | 준비도 0~4 → 4·3·2·2·1명 |
| 보호소 인원 | A 8명, B 6명 |

| 방법 | 필요 조사 | 큰 자재 | 작은 자재 | 시공 | 점수 |
|---|---|---|---|---|---|
| 사다리 발판 | 남은 교각 | 사다리 2 | — | 2시간 | 1 |
| 간이 가교 | 남은 교각 | 사다리 2, 강철 발판 2 | 로프 2, 고정 벨트 2 | 6시간(인력 1명당 −1, 최소 3) | 2 |
| 하천 바닥 우회 | 둑 아래 길 | 사다리 2 | 로프 1 | 1시간 | 0 |

공사 현장에는 사다리 3, 강철 발판 2, 고정 벨트 2가 있다.

결과 계산은 다음과 같다(준비도로 정한 남는 인원을 R, 방치로 잃은 인원을 NL이라 한다).
- **A-2**: 첫 무리 max(1, 8−NL−R)명과 동림이 건너온다. R명과 NL명은 데려오지 못한다. 정신력 −5. 석현은 떠난다.
- **A-1**: 첫 무리에 max(1, R−1)명이 더해지지만 동림을 잃는다. 정신력 −20. 그 뒤 동림 만남은 다시 일어나지 않는다.
- **B**: 6−NL−R명이 살아 나온다. 준비도 2 이상이면 B_Light, 미만이면 B_Heavy(동림 중상)다. 두 경우 모두 영숙은 돌아오지 않고, 석현은 협력한다. 정신력 −10.

## 설계와 다르게 한 점

- **저장 스키마 버전을 올리지 않았다.** 대신 `UpgradeLateStory`처럼 몇 번이고 다시 적용해도 되는 `UpgradeBrokenPath`를 두었다. 3막 이전 저장은 장소 2곳과 빈 진행 상태를 얻는다.
- **고립 보호소는 갈 수 있는 장소로 만들지 않았다.** 건너편은 무전과 결과 장면으로만 전해진다. "보이지 않는 곳의 상황은 무전으로만"이라는 설계 의도를 더 강하게 따랐다.
- 철물점의 추가 사다리는 넣지 않았다. 공사 현장 재고(사다리 3)만으로 모든 방법을 만들 수 있다.

## 진행 중 다른 이야기 멈춤

- 3막이 진행되는 동안 후반 이야기 장면(`TryBeginLateStory`)은 시작하지 않는다.
- 3막이 진행되는 동안 동림 반복 만남도 일어나지 않는다. A-1 뒤에는 동림 만남이 영구히 사라진다.
- 장면이 열려 있으면 행동할 수 없다(`CanAct`).
- 집 화면에는 후반 이야기 안내 대신 "보행교·공사 현장으로" 안내가 나온다.

## 테스트 진입

- **메뉴 → 개발용 · 3막 「끊어진 길」 테스트 진입**: 에디터와 검증 빌드에서만 보인다. 현재 기록을 덮어쓴다.
- 인스펙터의 `VanishingDaysGame › Start At Act3 In Editor`를 켜면 에디터 재생 시 바로 핵심 선택부터 시작한다. 이 경우에도 에디터 저장 기록을 덮어쓴다.
- 진입 상태(`SurvivalState.Act3TestStart`)는 꾸며 만든 값이 아니다. 실제 진행 함수로 오프닝 → 가락시장 → 동림 만남 → 첫 동행까지 플레이한 뒤 DAY 21 09:00으로 옮긴다. 신뢰 4(지원 인력 1명), 식수와 로프·들것 재료를 넣어 둔다.

## 검증 (2026-11-08)

- `PrototypeBuilder.Validate`: 기존 15종과 `BrokenPathChecks`(202개 단언)가 모두 통과했다.
  - A-1, A-2, B_Light, B_Heavy를 실제 함수로 끝까지 진행하고 인원 계산을 확인했다.
  - 신뢰 0/3/6에 따른 인력 0/1/2명을 확인했다.
  - 운반 제한(세 번째 큰 자재 거절, 고정 벨트 일괄)을 확인했다.
  - 준비도 계산과 남는 인원 표를 확인했다.
  - 버팀 → 흔들림 → 위급 시각과 방치 상한 3명(지연 일수는 계속 증가)을 확인했다.
  - 현장 작업 중간과 철수 장면, 완료 후에 저장했다가 불러오면 그대로 이어지는 것을 확인했다.
  - 3막 이전 저장(장소 10곳)이 12곳으로 올라가는지, 잘못된 단계 저장을 거부하는지 확인했다.
  - 진행 중 후반 이야기가 멈추는지, A-1 뒤 동림 만남이 없는지 확인했다.
- 기존 검사 중 옛 저장을 흉내 내는 세 곳(`RadioStoryChecks`, `WorldProgressionChecks`, `LateStoryChecks`)은 새 장소 2곳도 지우도록 고쳤다.
- 검증 플레이어 `-vdAct3`은 실제 버튼으로 두 경로를 진행했고, 스크린샷은 `Builds/Act3Verification/`에 있다.
  - A 경로(인력 2명): 핵심 선택 → 무전 → 조사 3종 → 계획 비교(`?` 표시) → 간이 가교 → 운반 2회 → 로프·들것 제작 → 시공 → 철수 → A-2 → 결별 → 저장 확인.
  - B 경로(인력 0명): 하천 바닥 우회 → 혼자 운반 2회 → 시공 → B_Heavy → 영숙의 빈자리.
- 기존 UI 검사 `-vdDialogue`, `-vdLife`, `-vdQa`, `-vdInterfaceRepair`, `-vdTutorial`, `-vdBalance`, `-vdStorage`도 통과했다.
- `-vdCraft`, `-vdErasure`, `-vdSupply`, `-vdSmoke`는 이번에 다시 돌리지 않았다. 이 넷은 이전 변경 전 코드에서도 실패한다([대사 연출 기록](Dialogue-Implementation.md) 참고).

## 남은 것

- **2단계**에서 앞 이야기(2막 끝 중계실 장면)와 연결해야 한다. 지금은 테스트 진입으로만 들어간다.
- 수치는 모두 임시값이다. 특히 방치 속도, 준비도 표, 보호소 인원은 실제 플레이 후 조정이 필요하다.
- 공사 현장을 2막에 미리 여는 일은 3단계로 넘긴다.
- 3막 결과 플래그(`DonglimAlive`, `YeongsukState`, `SeokhyeonCoop`)는 저장되지만, 아직 4막·엔딩에서 읽지 않는다.
- 인물 초상은 여전히 자리표시 그림이다.
