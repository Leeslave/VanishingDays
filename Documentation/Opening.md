# 오프닝 v1.0 연결

Prototype 씬에서 Play → 게임 시작 → 군중심리 문답 → 패닉 문답 → 이석현의 기록(2030년 5월 12일, 5월 13일, 6월 5일, 12월 26일) → 실종 고지 → 닉네임 → 2031년 2월 26일 기록지 #001 → 다음 → 기존 본편 순서입니다. 자동 넘김은 없습니다.

## 수정 지점

- `Assets/Resources/Opening/OpeningScriptData.json`: 원고, 날짜, 작성자, 버튼과 화면 ID. 이석현의 네 날짜 기록은 2026-10-22 사용자 요청에 따라 현장 묘사와 기록자의 반응을 보강했습니다. 사건·단서·날짜·마지막 문장은 유지하며, 질문·정의·실종 고지·플레이어 기록지는 기존 기획서 문구를 보관합니다. 수정된 일지 전체는 `OpeningDiary.md`에서도 읽을 수 있습니다.
- `OpeningFlowController`: 현재 화면, 두 질문의 응답, 닉네임. `OnOpeningCompleted(string)`은 마지막 다음에서 한 번만 호출합니다.
- `OpeningScreenView`: 기존 uGUI·한글 글꼴·9:16 화면을 사용합니다. 본문은 가변 높이 스크롤 영역이고 버튼은 그 밖에 고정됩니다. 표시 문자열은 리치 텍스트로 해석하지 않습니다.
- `OpeningInputBridge`: 기존 Input System에서 uGUI InputField가 요청하는 IME 조합 문자열·활성화·후보창 위치를 연결합니다. 한글 조합 도중에는 문자 필터와 길이 제한을 적용하지 않고, 확정된 이름을 제출할 때 검증합니다.
- `VanishingDaysGame.StartMainGame(string)`: 오프닝 완료 이벤트를 받아 기존 게임 상태를 만들고, `SurvivalState.PlayerNickname`을 기존 JSON 저장에 포함합니다. 이석현의 원고 작성자와 설문 응답은 변경하지 않습니다.

## 닉네임

앞뒤 공백 제거 후 한글·영문·숫자 1~12자만 허용합니다. 공백·특수문자·길이 초과는 기록 시작 버튼을 비활성화합니다. 입력 중의 한글 자모도 허용합니다. Enter는 입력 확정만 하며, 화면 전환은 기록 시작 버튼을 눌러야 합니다.

## 검증

Unity 메뉴 `Vanishing Days/Validate opening flow`: 4가지 문답 조합, 도입 문장, 날짜와 순서, 실종 고지, 닉네임 경계값·정규화, 원 작성자 유지, 마지막 세 문장, 금지 정보, 완료 전 무호출·재진입 및 반복 클릭 시 완료 이벤트 1회 호출을 검증합니다.

2026-10-22 검증 결과: 상태 전환 137개 assertion 통과. Unity에서 리소스 로드 및 Windows 빌드 통과. 540×960 실제 렌더링에서 13개 화면, 긴 기록 스크롤, 공백 제출 비활성화, uGUI 한글 확정 문자 입력, Input System IME 조합 및 화면 표시, 닉네임 바인딩, 본편 전환, JSON 저장 왕복 통과. 검증 중 기존 저장 데이터는 복원합니다. 화면은 `OpeningRecordPreview.png`, `OpeningNicknamePreview.png`에 보관합니다.

일반 빌드에는 오프닝 건너뛰기 UI가 없습니다. 기존 본편 빠른 진입 옵션과 화면 캡처용 코드는 `UNITY_EDITOR`에서만 실행됩니다.

남은 연결 지점은 없습니다. 모바일 OS별 한국어 IME 후보창과 소프트 키보드는 실제 기기에서도 확인해야 합니다. 배후 세계관, 추가 대화·전화, 신규 생존 기능과 P1 효과는 추가하지 않았습니다.
