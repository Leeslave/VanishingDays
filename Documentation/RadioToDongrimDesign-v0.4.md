# VANISHING DAYS — P1 기획서 v0.4
## 라디오 이후: SP 방송 → 생존자의 선택 → 군중 사고 → 최동림 첫 등장

- 상태: **제안안 / 사용자 검토 전**
- 대상 브랜치: `feature/GameConcept` (`Leeslave/VanishingDays`)
- 작성 범위: 라디오 획득 직후부터 최동림 첫 만남까지. 해방전선대 합류와 한지우 요리 특채는 다음 단계(P1-B)로 분리.
- 기준: 현재 `Implementation-v0.3.md`와 `SurvivalState.cs`의 라디오 및 서사 게이트, 생존 루프를 존중함.

## 1. 목적 / 플레이 감정

초반부는 스토리 컷신 연속이 아닌 **생존 크래프팅 게임**으로 유지한다. 라디오를 얻었다고 NPC가 등장하거나 자동으로 특정 날짜로 건너뛰지 않는다. 라디오가 주는 정보 때문에 플레이어가 외출할 **유인**이 생기고, 직접 해당 장소를 조사하러 갔을 때 군중 사고로 이어져 최동림을 만난다.

중요한 플레이 감정: “먹을 것이 떨어지면 어떡하지?” → “방송에서 물자 정보를 들었다” → “위험할 수 있지만 가볼까?” → “사람이 모이면 오히려 위험하다” → “나를 구해준 남자가 그 사실을 먼저 알고 있었다.”

## 2. 현재 구현과 연결

현재 확인한 구현:
- `SurvivalState.Story.HasRadio`: 학교에서 3회 수색 시 라디오 확정 획득 (3회 수색 값은 TEMP_BALANCE).
- `ListenRadio()`: `approvedSPBroadcast`가 비어 있어 “지금은 수신되는 방송이 없다.” 출력. 원고가 있으면 `HasHeardSPBroadcast = true`.
- `CanTriggerDongrimFirstEncounter(bool approvedCrowdRescueCondition)`: 라디오 보유 및 별도의 구조 이벤트 조건 필요. 현재 일반 플레이에서는 호출자가 없어 최동림 등장하지 않음.
- 4개 초기 장소, HP/허기/부상, 일차/시간, 낮밤 조우, 집 약탈, 저장 구조는 유지.

본 P1에서 해야 할 연결은 '방송 텍스트' + '방송으로 인한 단서/지역 표시' + '플레이어가 직접 접근할 때 시작하는 군중 이벤트' + '최동림 구조 연출 및 플래그 저장'이다.

## 3. 진행 흐름 (날짜 강제 없음)

```text
초반 자유 생존 · 요리 · 파밍
    ↓
학교에서 라디오 획득 [기존 구현]
    ↓
집에서 라디오 켜기 (선택)
    ↓
SP 첫 방송 듣기 → '물자 배분 소문' 정보 획득
    ↓
기존 지역 탐색/생존 계속 가능
    ├─ 방송 단서를 무시하면 스토리 이벤트 발생 안 함
    └─ 새 임시 장소를 직접 방문하면 다음 단계 진입
          ↓
        인파와 소문을 확인
          ├─ 떠난다 → 안전하게 기존 생존 루프로 복귀 (재방문 가능)
          └─ 배급 구역 안으로 접근한다
                 ↓
             군중 패닉 → 안재현이 휩쓸림
                 ↓
             최동림이 좁은 통로로 끌어내 구출
                 ↓
             군중 집중 구역에서 소멸 발생/흔적 확인
                 ↓
             최동림과 짧은 대화 + 첫 만남 완료
                 ↓
             새 인물/조직 연결 단서 (다음 단계 P1-B 진입 전까지 자유 생존)
```

**중요:** 라디오를 획득해도 후속 사건이 자동 시작하지 않고, 방송을 듣는 즉시 구조 이벤트가 실행되지도 않는다.

## 4. SP 첫 방송 (대본 제안)

> [치직… 치지직…]
>
> **SP 기지국:** “여기는 SP 기지국입니다. 송출 상태가 불안정하여 일부 구간의 수신이 끊길 수 있습니다.”
>
> “현재 여러 지역에서 식량과 의약품의 부족을 호소하는 제보가 이어지고 있습니다.”
>
> “송파구 **가락시장 인근의 한 물류시설에서 생필품을 나눈다**는 제보가 접수됐습니다.”
>
> “다만 배분 주체와 운영 여부는 확인되지 않았습니다. 해당 정보를 확인하러 이동하시는 분들께서는 각별히 주의하시기 바랍니다.”
>
> “소재가 확인되지 않은 실종자에 대한 제보도 계속 접수하고 있습니다.”
>
> [잡음…]

- **장소명은 제안안**이다. 확정 전이라면 데이터에서 교체할 수 있어야 한다.
- 방송은 공식 배급 확정 공지가 아니라 검증되지 않은 제보이다. SP가 사람을 모으기 위해 일부러 유도하는 것처럼 보이지 않도록 주의한다.
- 방송에 소멸의 과밀/방치 법칙, 이석현의 실체, AI의 존재를 설명하지 않는다.
- 방송 후 **정보 카드**를 기록지에 남긴다: “송파구 가락시장 인근 물류시설에서 물자를 나눈다는 제보. 확인되지 않음.”
- 라디오는 앞으로 정기 정보원으로 확장하되 P1에서는 1개의 스토리 방송과 간단한 일반 방송만 필요하다.
- 플레이어가 첫 청취를 늦게 하더라도 상대 날짜가 깨지지 않게 “오늘 몇 시” 등의 고정 시각·기한 표현을 쓰지 않는다.

## 5. 신규 탐색 장소 (P1 이벤트형)

**임시 배분 장소 — 가락시장 인근 물류시설 (제안 명칭)**

| 항목 | 설계 |
|---|---|
| 해금 | SP 첫 방송 청취 후 지도에 '제보 장소' 아이콘 등장 |
| 유형 | 일반 파밍처가 아닌 스토리 이벤트 지역 |
| 시작 UI | 제보 내용, 위험 징후, 접근/철수 선택지 |
| 파밍 | 구조 이벤트 전까지 무한/확정 물자 지급 금지 |
| 시각 | 기존 이동 시간과 낮/밤 유지. 밤에 와도 군중 사고가 자연스러운 이유가 없으면 현장 제보 확인만 남기고 사고는 낮 시간 접근 시 발생하도록 설계 |
| 이탈 | 접근을 거절하면 기존 생존 활동으로 돌아갈 수 있음 |

**낮/밤 충돌 방지 설계:** P1 기본안에서는 낮(06:00~18:00)만 인파가 뚜렷해지고 군중 사건을 활성화. 밤에 방문하면 현장의 대기줄 흔적과 남겨진 안내문을 확인하고 귀환할 수 있다. 다음 낮에 접근 가능. 낮밤 경계에 이동/수색 시간을 적용하는 방식은 기존 엔진을 재사용할 것.

**주의:** '아무도 없는 밤에도 수백 명이 순식간에 생성되는 연출'을 피하고 싶다는 의도. 시간 조건은 스토리 이벤트의 사실감을 위한 제안이며 최종 수치 확정은 아님.

## 6. 군중 구조 이벤트 (필수 스토리 장면)

### 6-1. 접근

플레이어 내레이션:

> 건물 앞에는 생각보다 많은 사람들이 있었다.
>
> 누군가는 쌀 한 포대가 남았다고 했고, 누군가는 아침부터 한 개도 나누지 않았다고 했다.
>
> 누구 말이 맞는지 알 수 없었다.
>
> 나는 잠시 망설였다.

선택지:
- **한발 물러나 상황을 살핀다** → 위험 묘사 추가. 그 뒤 '접근한다/돌아간다'로 선택 가능.
- **배분 구역 가까이 간다** → 군중 사건 확정 진입.
- **돌아간다** → 귀가 또는 지도 복귀. 최동림 만나지 않음. 재방문 가능.

### 6-2. 패닉

> 누군가 ‘끝났다!’고 소리쳤다.
>
> 맨 뒤쪽에서 밀려온 사람들이 앞쪽으로 쏠렸다.
>
> 나는 발을 헛디뎠다. 사람들의 어깨와 팔이 시야를 가렸다.
>
> 도망치려 했지만 어느 방향이 출구인지조차 알 수 없었다.

이 단계는 오프닝 '군중심리/패닉'의 체험적 회수이다.

장면 중 작은 선택을 제공할 수 있다:
- **가방을 놓고 몸을 틀어 빠져나오려 한다** → 소지 물품 일부를 잃을 수 있으나 부상 확률 완화.
- **가방을 붙잡고 버틴다** → 소지 물품 손실 위험은 낮지만 부상 위험 증가.

**필수 주의:** 양쪽 중 어떤 선택을 해도 최동림이 구조한다. 선택은 자원/부상 결과에만 영향을 준다. 필수 컷신 진입 시 강제 사망 또는 불가피한 대량 HP 차감 금지. 자세한 수치는 TEMP_BALANCE로 둔다.

### 6-3. 최동림 구출

> 누군가 내 옷깃을 붙잡았다.
>
> “따라와! 여기 말고!”
>
> 남자는 무너진 펜스 옆의 좁은 통로로 나를 끌어냈다.
>
> 한참을 숨을 고르고 나서야 사람들의 비명이 들렸다.

대사 초안:

> **최동림:** “괜찮아? 숨부터 골라.”
>
> **안재현:** “방금… 무슨 일이었던 거죠?”
>
> **최동림:** “사람이 저렇게 모이면 꼭 일이 생겨.”
>
> **안재현:** “그걸 어떻게 아는데요?”
>
> **최동림:** “몇 번 봤거든. 믿든 말든 네 마음이고.”

### 6-4. 소멸 목격

> 아까까지 사람들이 몰려 있던 골목의 끝이 보이지 않았다.
>
> 임시 천막과 차량, 골목 일부가 말 그대로 지워진 듯 사라졌다.
>
> 최동림은 그 광경을 보고도 놀라지 않았다.

동림은 **과밀 소멸을 알고 있지만, 소멸의 모든 원인을 이해하지는 못함**. 본 장면에서 이론 강의를 시키지 않는다. 소멸 대상은 이벤트 지역의 일부로 제한하고 구체적인 규모는 연출·아트 리소스에 맞춰 결정한다.

### 6-5. 첫 만남 마무리

> **최동림:** “난 최동림이야. 예전엔 경찰이었어.”
>
> **안재현:** “저는 안재현이라고 합니다.”
>
> **최동림:** “살아남을 생각이면 혼자 움직일 때도 상황은 잘 살펴. 특히 사람들이 한꺼번에 몰려가는 곳은.”
>
> **최동림:** “내가 아는 사람들이 있어. 아직은 멀리 떨어져 지내지만… 다음에 얘기하지.”

이후 최동림은 떠난다. 플레이어는 기존 집·요리·탐사·휴식 루프로 복귀한다. '해방전선대' 가입은 이때 자동으로 이루어지지 않는다.

## 7. 게임플레이/연출 원칙

1. 라디오 전에는 기존 생존 루프만. SP/동림을 일찍 노출하지 않음.
2. 라디오 이후에도 유저가 방송을 안 들으면 초반 자유 생존 유지.
3. 방송 청취 후에도 즉시 컷신을 열지 않고 **플레이어의 방문 결정**을 기다림.
4. 군중 이벤트는 최초 1회. 다시 장소에 접근해도 구조/대사/보상 중복 불가.
5. 메인 스토리 이벤트의 초기 장소는 자원 무한 생성 파밍처가 아님.
6. 본편의 소멸 실제 공식, 사이버 소멸, SP 방송 생존 이유, 이석현의 자발적 잠적 등 **반전/스포일러 미공개**.
7. 초반에 플레이어에게 최동림에 대한 과도한 설명, 조직 가입, 한지우 등장까지 연속으로 강제하지 않음.
8. 시간/거리/조우/상실/상처는 기존 데이터와 저장 모델에 연동. 새로운 임시 수치는 `TEMP_BALANCE` 취급.
9. 안재현은 대본상의 인물명. UI 기록지의 작성자 표시는 현재 닉네임 입력 정책을 존중 (이름 매핑 정책 미정).

## 8. 구현 권장 사항 (코덱스 전달용)

### 8-1. 데이터

현재 `SurvivalDefinitions.json`에 `approvedSPBroadcast`가 비어 있음. 첫 방송 원고를 데이터로 연결하고, 차후 다회 방송으로 확장할 수 있도록 방송 ID와 노출 조건을 갖춘 구조를 선호. **이번 P1에서는 실제 라디오 음성 없이 텍스트로 먼저 구현** (오디오 필요시 추후).

이벤트 지역은 데이터 기반으로 표시. 지도에서 선택하면 기존과 동일하게 **정보 확인은 시간 소모 없음, 이동하기에서만 시간 소모**.

### 8-2. 진행 플래그

기존 재사용: `HasRadio`, `HasHeardSPBroadcast`, `DongrimRescueCompleted`, `HasMetDongrim`.

추가 예시(명칭 변경 가능):
- `SupplyRumorUnlocked`: 첫 방송에서 배급 정보 취득
- `SupplySiteVisited`: 제보 지역 최초 방문
- `CrowdIncidentStarted`: 실제 군중 이벤트 진입
- `CrowdIncidentResolved`: 구조 장면/소멸 목격/결과 확정
- `DongrimContactHintReceived`: 후속 챕터 연결 단서 수령

`HasRadio` 획득만으로 최동림을 등장시키지 않음. 군중 이벤트가 실제 발동할 때만 `CanTriggerDongrimFirstEncounter(approvedCrowdRescueCondition)`을 만족시키는 별도 승인 조건을 제공할 것.

### 8-3. 이벤트 저장 / 이중 실행 방지

사건 진행 중 앱이 종료되어도 선택지 및 중간 사건 상태가 복구돼야 함. 이벤트가 '장소 최초 방문'에만 연결되면 재접속 시 중복 또는 유실되지 않도록 챕터/스텝 상태 직렬화 필요. 기존 v0.3 JSON save를 깨지 않도록 명시적인 저장 버전/마이그레이션 정책을 적용할 것.

### 8-4. 임시 밸런스 정책

- 군중 이벤트 조우는 RNG로 실패하지 않는 **스토리 확정 이벤트**. 해당 장소에 접근하는 것은 플레이어 선택.
- 무조건적인 사망 없음. 선택에 따른 부상·물품 손실은 별도 `TEMP_BALANCE`.
- 강제 가입/강제 아이템 지급/강제 여러 날 경과 없음.
- 새 장소 이동/수색 시간은 기존 송파구 4장소 밸런스와 비교해 **임시**로 설정.

### 8-5. 검증 (최소 수용 조건)

| 시나리오 | 기대 결과 |
|---|---|
| 라디오 없이 기존 장소 파밍 | SP 방송 불가, 최동림 등장 불가 |
| 라디오 획득만 함 | 방송 선택 가능, 군중 사건 미발생 |
| 첫 방송 청취 | 제보 카드 + 임시 장소 해금, 하루/시각 임의 변경 없음 |
| 방송 후 집에서 계속 생활 | 메인 스토리 자동 진행 없음 |
| 장소 확인만 함 | 방문 처리/시간/난수/이벤트 미변경 |
| 새 장소 방문 후 돌아감 | 군중 구조 안 일어남, 다시 접근 가능 |
| 사건 접근 후 선택 | 어떤 결과에서도 최동림 구조, 피해/손실은 선택에 따라 달라짐 |
| 사건 중 강제 종료 후 이어하기 | 동일 단계 복구, 중복 아이템/중복 동림 없음 |
| 첫 만남 완료 | `HasMetDongrim = true`, 자유 생존 복귀, 조직 가입 플래그는 `false` |
| 첫 만남 완료 후 재방문 | 구조 이벤트 중복 없음 |

## 9. 다음 단계(P1-B) — **이번 구현 범위에서 제외**

동림의 연락처/단서를 따라 해방전선대 생존자들을 발견. 최동림은 소규모 분산형 점조직을 조직 중이다. 여성 부대장 한지우는 외부인 안재현의 합류를 반대하고, 안재현의 뛰어난 요리 능력이 평가되어 **요리 특채**로 합류하는 방향. **한지우와 동림의 합류 논쟁, 요리 시험의 재료/레시피 및 거점 위치는 별도 확정 필요**.

## 10. 확인 필요 항목

- 임시 배분 장소를 가락시장 인근 물류시설로 사용할지 (제안 지명)
- 군중 사건이 낮에만 가능한지 (현재 기본 제안)
- 군중 소멸을 플레이어가 직접 볼지, 구출 후 흔적만 볼지 (현재 후자에 가까움)
- 최동림이 현장에서 남기는 연락 단서의 형태/장소
- 구조 이벤트 중 부상·물품 손실의 최종 밸런스

확정되지 않은 부분은 임시값으로 두고, 메인 세계관 정답을 임의로 추가하지 않는다.
