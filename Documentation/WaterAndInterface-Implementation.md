# 식수 접근성과 생존 UI

- 하단 **식수 관리**에서 생수 보유량과 혼탁한 물을 확인한다. 집에서 설비 없이 생활용수 모으기(2시간, 혼탁한 물 2병) → 물 끓이기(1시간, 부르스타, 혼탁한 물 2병 → 생수 2병)를 반복한다. 가스는 기존 설정대로 충분하다.
- 생활용수는 수색 풀과 별개이며 탐색 물자를 재생하지 않는다. 기존 저장에도 새 제작법이 즉시 적용된다. 외출 중에는 작업할 수 없다.
- 설비를 만들면 집수통 회수(1시간, 혼탁한 물 3병) → 정수(1시간, 3병 → 3병)로 생산 효율이 높아진다.
- **지금 물을 마신다** 또는 물품의 **마시기**는 접근 가능한 생수 1병으로 목마름과 식수 경과 시간을 초기화한다. 시간은 소모하지 않는다. 집에서는 창고 우선, 외부에서는 소지품만 사용한다. 갈증이 없으면 물을 낭비하지 않는다. 6시간 주기 자동 식수도 유지한다.
- 식수 없음 또는 목마름 60 이상, 졸림 60 이상이면 상단 경고가 유지된다. 경고를 눌러 식수 관리 또는 수면/귀가로 연결한다. 행동 후 새로 경고 상태에 들어가면 이미지 영역에 확인 알림을 띄운다. 회복하면 경고가 해제된다.
- 생성 이미지 `Assets/Resources/Art/SurvivalAtlas.png`: 은신처 배경과 주전자·침구·배낭·일지·지도·공구·붕대·식량 8개 아이콘을 하나의 아틀라스로 구성했다. 생활 화면, 메뉴 버튼, 제작 목록, 물품 목록에 연결했다. 한국어 설명과 수량은 별도 텍스트로 유지한다.

## 검증

`Vanishing Days/Validate renewable water and warnings`에서 보통·어려움의 반복 생산, 식수 소비보다 많은 생산량, 직접 음수 비용·수치 초기화, 외출 시 물 접근 제한, 경고 임계값·해제, 사망·조우 행동 차단을 확인한다. 통합 규칙 검증에도 포함한다. 기존 제작 검증은 설비의 변경된 시간·생산량을 확인한다.

통합 규칙·오프닝 검증 787개 통과. `-vdSupply` 검증 플레이어에서 실제 버튼으로 수집·끓이기·직접 음수·6시간 수면을 수행하고 경고 표시·해제 및 저장 복원을 확인했다(`Builds/WaterAccessPlayerUIVisible.log`, `VD_WATER_ACCESS_UI_OK`). 화면 캡처는 `Builds/WaterAccessVerification/01-SHELTER-WARNINGS.png`~`04-RECOVERED.png`에 있다. 검증용 코루틴은 일반 빌드에서 제외한다.

일반 Windows(`Builds/Windows/VanishingDays.exe`)와 WebGL(`Builds/WebGL`) 빌드 성공. 웹 배포 소스 `sites/vanishing-days-web/dist`에 새 빌드를 반영하고 gzip 해제·WebAssembly 유효성·로더 해시·브라우저 저장 동기화 설정을 확인했다. 실서버 게시는 수행하지 않았다.

수집량과 소요 시간, 경고 임계값은 플레이 피드백에 따라 조정할 임시 밸런스다. 실제 기상·빗물 시뮬레이션은 포함하지 않는다.
